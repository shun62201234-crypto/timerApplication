# タイマー・アラームアプリ 要求仕様
## 1. 概要
本アプリケーションは、ブラウザ上で動作するタイマー・アラームアプリケーションである。
**設定した時間をカウントダウンするタイマー機能と、指定した時刻に通知を行うアラーム機能**を実行できる。
ユーザーはタイマー機能とアラーム機能を切り替えて利用できる。
タイマー機能とアラーム機能は独立して動作し、同時に通知が発生した場合も、それぞれの通知を個別に管理する。
画面上の表示、入力方法、ボタン状態、選択状態等の詳細については、別途「画面仕様」を参照する。

## 2. 対象環境
### 2.1  開発環境
-   使用言語: TypeScript
-   使用ツール: Vite, VSCode

### 2.2 動作環境
-   Google Chrome 最新版
-   Microsoft Edge 最新版

## 3. 機能要求
### 3.1 共通
-   タイマーモードとアラームモードを切り替えられること。
-   タイマーとアラームの状態を、それぞれ独立して管理できること。
-   モード切替時も、それぞれの状態が保持されること。
-   タイマー終了時またはアラーム時刻到達時はユーザーへ通知すること。
-   タイマー通知とアラーム通知が同時に発生した場合、それぞれの通知を個別に表示・管理できること。
-   片方の通知を操作しても、もう片方の通知に影響しないこと。
-   モード切替時も、発生済みで操作されていない通知を引き継ぐこと。
-   通知音を再生・停止できること。

### 3.2 タイマー
-   タイマー時間を設定できること。
-   タイマー時間は、時間・分・秒を設定できること。
-   タイマーを開始、カウントダウン、一時停止、再開およびキャンセルできること。
-   タイマー終了時にユーザーへ通知すること。
-   タイマー履歴を保存できること。
-   保存した履歴からタイマーの時間を再設定できること。

### 3.3 アラーム
-   アラーム時刻を設定できること。
-   アラーム時刻は、時間・分を設定できること。
-   設定したアラームを保存できること。
-   保存したアラームをON/OFF切り替えできること。
-   ON状態のアラームは、設定時刻になると通知すること。
-   OFF状態のアラームは、設定時刻に通知しないこと。
-   アラーム通知中にスヌーズを利用できること。
-   保存したアラームを削除できること。
-   同一時刻のアラームを複数登録できること。
-   削除またはOFFにしない限り、翌日以降も設定時刻に通知すること。

## 4. 非機能要求
### 4.1 データ保存
-   アラーム設定およびタイマー履歴は、ブラウザ終了後も保持する。
-   アラーム設定およびタイマー履歴はLocalStorageに保存する。
-   LocalStorageから保存データを読み込めない場合は、読み込めなかったデータを初期状態として扱う。
-   LocalStorageへの保存に失敗した場合、画面上の変更を取り消して変更前の状態に戻し、エラー内容をコンソールへ出力する。
-   保存に失敗した操作について、通知の終了、スヌーズ予約の取消し、タイマーの開始等の付随処理を実行しない。
-   保存に成功した場合に限り、状態の変更と、それに伴う処理を確定する。

### 4.2 時刻
-   アラームの時刻判定は**日本標準時（JST）**を使用とする。
-   アラームの時刻判定には、現在時刻を使用する。
-   アラームの時刻判定は1秒間隔で実行する。
-   ブラウザの負荷やスリープ等により、通知が設定時刻より遅れる場合がある。
-   ブラウザや端末が停止・スリープしている間に設定時刻を過ぎた場合、復帰後に過去の時刻の通知は行わない。ただし、ブラウザ起動時の特別な判定については、5.6「ブラウザ終了・再起動」に従う。
-   アラーム保存時は、現在時刻と設定時刻の「時・分」が一致していれば、保存直後に通知する。秒は判定しない。
-   同じブラウザの起動中は、同じアラームについて、同じ日時に通知するのは1回だけとする。
-   一度通知したアラームについては、同一日時の判定中に重複して通知しない。
-   ブラウザ再起動時の通知判定については、5.6「ブラウザ終了・再起動」に従う。

### 4.3 音声
-   タイマー終了時およびアラーム通知時に通知音を再生する。
-   通知音の再生時間は最大60秒とする。
-   通知終了操作を行った場合、対象通知の通知音を停止する。
-   スヌーズ操作を行った場合、対象の通知音を直ちに停止する。
-   通知音の音量は、PC本体のシステム音量に従う。
-   アプリ内に音量調整機能は設けず、音量の調整はPC側で行う。
-   音声の再生に失敗した場合は、エラー内容をコンソールへ出力する。
-   複数の通知が発生した場合、最初に発生した通知1件だけが通知音を再生できる。
-   タイマー通知とアラーム通知の間に優先順位は設けず、先に発生した通知を優先する。同時に発生した場合は、先に通知処理されたものを優先する。
-   通知音を再生できる通知は、最大60秒間、通知音を再生する。
-   通知音の再生に失敗した場合も、次に発生した通知へ再生できる権利を移さない。
-   通知音の再生中に発生した後続の通知は、通知音を再生しない。
-   後続の通知は、先行する通知音の再生が終わった後も、遅れて通知音を再生しない。
-   通知音の再生が終了したら、次に発生する通知が通知音を再生できる状態に戻す。
-   スヌーズ操作によって通知音を途中で停止した場合も、その時点で次に発生する通知が通知音を再生できる状態に戻す。
-   通知音を再生できる状態に戻った後に新しい通知が発生した場合、その通知は通知音を再生できる。
-   通知音を再生しない場合も、通知の表示と通知状態は通常どおり維持する。
-   通知音の再生に失敗した場合も、通知は終了しない。ユーザーが終了またはスヌーズを操作するまで、通知の表示と状態を維持する。

## 5. 共通機能仕様
### 5.1 モード切替
-   タイマーとアラームの状態は、それぞれ独立して管理する。
-   タイマー動作中にアラームモードへ切り替えても、タイマーは動作を続ける。
-   タイマーが一時停止中にアラームモードへ切り替えても、一時停止状態を保持する。
-   アラームモードからタイマーモードへ切り替えても、タイマーの状態を保持する。
-   保存済みアラーム設定は、モードを切り替えても保持する。
-   モード切替によって、タイマーの開始・一時停止・再開・キャンセルや、アラームのON/OFF状態を変更しない。
-   タイマーのキャンセル確認中は、モード切替を受け付けない。
-   タイマーのキャンセル確認が終了した後は、通常どおりモード切替を受け付ける。

#### 5.2 通知の基本管理
-   アラーム通知とタイマー終了通知は、独立して管理する。
-   通知ごとに、通知ID、通知状態、表示位置、必要なスヌーズ情報を管理する。
-   通知状態は、次の3種類とする。
   -   `通知中`(active)：通知が表示され、終了またはスヌーズ操作を待っている状態。
   -   `スヌーズ中`（snoozed）：通知を一時的に非表示にし、再通知を待っている状態。
   -   `終了`（ended）：通知が終了し、管理対象から除外される状態。
-   スヌーズ操作を行うと、通知中からスヌーズ中へ移る。
-   スヌーズ時間が経過すると、スヌーズ中から通知中へ戻る。
-   終了操作を行うと、通知は終了状態となり、その後、管理対象から除外する。アラームOFFまたはアラーム削除によって通知を終了する場合も、同じ終了処理を行う。
-   通知数に上限を設けない。
-   タイマーおよびアラームの通知は発生ごとに個別に管理・表示し、スヌーズ中の通知も管理対象として維持する。
-   タイマー終了時またはアラーム時刻到達時に、対象の通知を発生させる。
-   複数の通知が同時に発生した場合も、それぞれを個別に管理・表示する。
-   通知に対する終了またはスヌーズ操作は、操作対象の通知だけに適用する。
-   一方の通知を操作しても、他の通知の状態、処理、表示順序は変更しない。
-   通知は、終了またはスヌーズなどの操作が行われるまで表示を続ける。
-   通知音の再生が終了しても、通知の終了操作が行われるまでは通知状態を維持する。
-   通知終了操作は、対象通知が通知中またはスヌーズ中の場合に受け付ける。
-   通知終了操作を受け付けた場合、対象の通知を終了する。

### 5.3 通知の振り分けルール
-   通知の表示位置は、現在選択されているモードと通知の種類に応じて決定する。
-   タイマーモードでは、タイマー終了通知を中央表示の対象とし、アラーム通知は左下表示の対象とする。
-   アラームモードでは、最初に発生したアラーム通知を中央表示の対象とし、それ以外のアラーム通知およびタイマー終了通知は左下表示の対象とする。
-   中央に表示できる通知は、常に1件だけとする。
-   同じ時刻に複数のON状態のアラームが発生した場合は、すべて通知する。
-   同時刻に複数のアラームが発生した場合、アラーム設定一覧の一番上にあるものを最初のアラームとして扱う。
-   最初のアラームは、中央表示が空いている場合に限り中央へ表示する。中央が既に別の通知で使用されている場合は、左下へ表示する。
-   同時刻に発生したその他のアラームは、左下表示の対象とする。
-   中央表示中の通知が終了またはスヌーズされた場合、既に発生している別の通知を中央表示へ移動しない。
-   中央表示の通知がなくなった場合、中央表示は空の状態とする。
-   中央表示が空いた後に新しい通知が発生した場合は、その時点のモードに応じた通常の表示ルールで表示位置を決める。
-   既に左下に表示されている通知を、中央へ移動することはしない。
-   スヌーズによる再通知時、中央表示が空いていれば、スヌーズ操作時点の表示位置を維持する。
-   スヌーズによる再通知時、中央表示が既に別の通知で使用されていれば、再通知を左下表示へ移す。
-   左下表示に表示されている通知は、他の通知の終了やスヌーズによって表示位置を変更しない。

### 5.4 通知の表示順序
-   左下表示の通知は、発生した順に並べる。
-   新しい通知は、既存の通知の一番下に追加する。
-   同時刻に複数のアラームが発生した場合は、アラーム設定一覧の上から順に扱う。
-   通知の終了またはスヌーズによって、残っている通知の順序を変更しない。
-   スヌーズによる再通知は、スヌーズ操作時の表示位置を基本として維持する。
-   スヌーズ前と再通知後では、同じ通知IDを使用する。スヌーズ中も通知IDは変更しない。
-   スヌーズによる再通知先に同じ表示位置の通知が既に存在する場合は、既存通知の順序を変更せず、再通知をその位置の一番下に追加する。
-   中央表示への再通知時に中央表示が既に別の通知で使用されている場合は、5.3のルールに従い左下表示へ移す。
-   中央表示から左下表示へ移された再通知は、左下表示の一番下に追加する。その後のスヌーズ再通知では、左下表示の位置を維持する。

### 5.5 モード切替時の通知状態・表示位置
-   モードを切り替えても、発生済み通知の状態を維持する。
-   通常の未操作通知は、切替後のモードに合わせて表示位置を振り分け直す。
-   モード切替前に中央表示されていた通常の未操作通知は、切替後に左下表示へ移す。
-   モード切替によって、通知の終了・解除・スヌーズ状態の変更を行わない。
-   モード切替によって、通知音の再生状態を解除または変更しない。
-   スヌーズ中の通知とスヌーズによる再通知は、スヌーズ操作時の表示位置を基本として維持する。ただし、中央表示への再通知時に中央表示が別の通知で使用されている場合は、5.3のルールに従い左下表示へ移す。
-   モード切替によって、未操作通知を消去しない。

### 5.6 ブラウザ終了・再起動
-   タイマーおよびアラーム機能は、ブラウザが起動している間に動作する。
-   アプリの状態管理は、ブラウザ終了時の処理に依存しない。
-   ブラウザ終了時の処理を実装する場合も、その処理が実行されなくても状態が不整合にならないようにする。
-   ブラウザ起動時に、保存済みのアラーム設定とタイマー履歴を読み込む。
-   ブラウザ再起動時に復元するのは、保存済みのアラーム設定とタイマー履歴だけとする。
-   動作中または一時停止中のタイマー状態、発生済みの通知状態、アラームのスヌーズ状態および予約済みの再通知は復元しない。
-   設定中で保存されていないアラーム時刻は復元しない。
-   ブラウザ再起動時、タイマーは初期状態とする。
-   ブラウザ起動時に、現在時刻とON状態のアラーム設定時刻の「時・分」が一致していれば、起動直後に通知する。秒は判定対象外とする。
-   同じ日の同じ時刻でも、ブラウザを起動するたびに上記の条件を満たしていれば通知する。
-   この起動時の判定では、過去に同じアラームを通知したかどうかによる重複防止は行わない。
-   設定時刻より後の分にブラウザを起動した場合、過去のアラーム通知は行わない。
-   起動時に発生したアラーム通知は、通常のアラーム通知と同様に管理する。

## 6. タイマー機能仕様
### 6.1 時間設定
-   タイマー設定時間の**初期値は「00:00:00」**とする。
-   入力可能な範囲は、**時間(0～23)、分(0～59)、秒(0～59)**とする。
-   設定した時間をタイマー設定値として保持する。
-   00:00:00の場合、**開始操作を受け付けない**。
-   00:00:00以外の場合、タイマーを開始できる。

### 6.2 開始
-   タイマーを開始すると、設定時間からカウントダウンを開始する。
-   タイマー開始時に、設定時間をタイマー処理内で保持する。
-   タイマー開始後は、設定時間を変更できない。
-   タイマー開始時に、開始時点の設定時間を履歴として保存する。
-   タイマー履歴の保存に失敗した場合、タイマーを開始しない。開始前の状態を維持する。
-   アラームモードに切り替えても、タイマーのカウントダウンを継続する。

### 6.3 カウントダウン
-   タイマーの残り時間は、終了予定時刻と現在時刻の差から計算する。
    -   終了予定時刻 = 開始時刻 + 設定時間
    -   残時間 = 終了予定時刻 - 現在時刻
-   残時間は秒単位で管理する。
-   残時間が`00:00:00`となった場合、カウントダウンを終了する。

### 6.4 一時停止・再開
-   カウントダウン中は、一時停止操作を受け付ける。
-   一時停止した時点の残り時間を、秒単位で保存する。
-   一時停止中はカウントダウンを停止する。
-   再開操作を行った場合、保持している残時間からカウントダウンを再開する。
-   再開後も、再び一時停止できる。
-   カウントダウン中および一時停止中は、キャンセル操作を受け付ける。

### 6.5 キャンセル
-   カウントダウン中または一時停止中にタイマーをキャンセルできる。
-   キャンセル操作を行うと、キャンセル確認を表示する。
-   キャンセル確認中は、タイマーのカウントダウンを一時停止する。
-   「はい」を選択した場合、タイマーをキャンセルする。
-   キャンセルしたタイマーの設定時間および残時間を破棄する。
-   キャンセルしたタイマーの履歴は削除せず、保持する。
-   「いいえ」を選択した場合、キャンセル確認を始める前の状態に戻る。
-   キャンセル確認前がカウントダウン中の場合は、カウントダウンを再開する。
-   キャンセル確認前が一時停止中の場合は、一時停止状態へ戻る。

### 6.6 終了通知
-   タイマーの残時間が`00:00:00`となった場合、カウントダウンを終了し、タイマー終了通知を発生させる。
-   タイマー終了通知は、アラーム通知とは独立して管理する。
-   タイマー終了通知は、ユーザーが「終了」を操作するまで表示と通知状態を維持する。
-   通知音の再生は、4.3「音声」の仕様に従う。
-   タイマー終了通知で受け付ける操作は「終了」操作のみ受け付ける。
-   アラーム通知中にタイマーが終了した場合も、タイマー終了通知を発生させる。
-   タイマー終了通知の操作は、アラーム通知の表示・状態・処理に影響しない。
-   タイマー終了通知中は、設定時間、残り時間、終了予定時刻を保持する。
-   タイマー終了通知に対して「終了」操作を行った場合、タイマーの終了状態を解除し、設定時間、残り時間および終了予定時刻を初期化する。
-   タイマーを初期化しても、保存済みの履歴は削除しない。

### 6.7 履歴保存
-   保存する履歴は、タイマー開始時点の設定時間とする。
-   タイマー開始時に保存した履歴は、タイマー終了後も保持する。
-   タイマーをキャンセルした場合も、開始時に保存した履歴を削除せず保持する。
-   タイマー履歴は最大5件保持する。
-   6件目の履歴を保存する場合、最も古い履歴を削除する。
-   新しい履歴は一覧の一番上(先頭)に追加する。
-   同じ時間の履歴を複数保存できる。

### 6.8 履歴再利用
-   保存したタイマー履歴を選択して、タイマー設定に再利用できる。
-   履歴を選択した場合、履歴に保存されている時間をタイマー設定時間へ反映する。
-   履歴を選択しただけではタイマーを開始せず、開始待ち状態とする。
-   同時に選択できる履歴は1件だけとする。
-   別の履歴を選択した場合、以前の選択を解除し、新しく選択した履歴を選択状態とする。
-   履歴の選択を解除した場合、タイマー設定時間を`00:00:00`へ戻す。
-   タイマー設定時間が`00:00:00`以外であれば、タイマーを開始できる。
-   タイマーが動作中、一時停止中または終了通知中の場合は、履歴を選択して設定時間を変更できない。

## 7. アラーム機能仕様
### 7.1 アラーム登録
-   アラームを登録できる。
-   アラームは**最大5件まで登録**できる。
-   登録件数が5件の場合、新たなアラームを登録できない。
-   同一時刻のアラームを複数登録できる。

### 7.2 時刻設定
-   アラーム設定時刻の**初期値は「00:00」**とする。
-   設定できる範囲は、**時間(0～23)、分(0～59)**とする。
-   `00:00`も有効なアラーム設定時刻として扱う。
-   設定中のアラームは、保存するまで登録済みとして扱わない。

### 7.3 保存
-   設定したアラームを保存できる。
-   時刻が`00:00`の場合も保存できる。
-   保存直後のアラーム状態はONとする。
-   保存したアラームは、通知が発生した後も保持する。
-   保存したアラームは、削除またはOFFにしない限り、翌日以降も同じ時刻に通知する。
-   保存したアラームがONの場合、4.2「時刻」のルールに従って現在時刻と設定時刻を照合する。
-   照合した結果、時・分が一致していれば、保存直後に通知する。秒は判定しない。
-   アラームの保存に失敗した場合、アラームを登録せず、保存前の状態を維持する。

### 7.4 ON/OFF
-   保存したアラームはON/OFFを切り替えできる。
-   ON状態のアラームは、設定時刻になると通知する。
-   OFF状態のアラームは、設定時刻になっても通知しない。
-   アラームをOFFにすると、そのアラームに紐づく発生済みの通知を終了する。
-   対象の通知がスヌーズ中の場合は、予約済みの再通知も取り消す。
-   OFFにしたアラームに紐づく通知音が再生中の場合は、その通知音を停止する。
-   ON/OFF状態の変更は保存する。
-   アラームを削除していない限り、ON/OFF状態を保持する。
-   ON/OFFの保存に失敗した場合は、変更前の状態に戻す。
-   保存に失敗した場合は、通知の終了や再通知予約の取消しなども行わない。

### 7.5 通知
-   ONのアラームが設定時刻になると、アラーム通知を発生させる。
-   通知音の再生は、4.3「音声」の仕様に従う。
-   通知音の再生が終わっても、通知終了操作が行われるまで通知状態を維持する。
-   通知が終了しても、アラーム設定とON/OFF状態は保持する。
-   アラーム時刻の判定および過去時刻の扱いは、4.2「時刻」の仕様に従う。
-   同じブラウザの起動中は、同じアラームについて、同じ日時に通知するのは1回だけとする。
-   同じ時刻に複数のON状態のアラームが通知対象になった場合は、すべて通知する。
-   同時刻に発生した各アラーム通知は、それぞれ独立して管理する。
-   各アラーム通知は個別に終了またはスヌーズできる。
-   1件のアラーム通知を操作しても、他のアラーム通知の状態や処理に影響しない。
-   タイマー動作中にアラーム時刻へ到達した場合も、アラーム通知を行う。
-   タイマー終了通知中にアラーム時刻へ到達した場合も、アラーム通知を行う。
-   アラーム通知は、タイマー終了通知とは独立して管理する。
-   アラーム通知で受け付ける操作は「終了」または「スヌーズ」とする。

### 7.6 スヌーズ
-   アラーム通知中にスヌーズ操作を行える。
-   スヌーズ操作を行うと、対象の通知を一時的に非表示にし、5分間のスヌーズ状態にする。
-   スヌーズ時間は5分とし、スヌーズ回数に上限を設けない。
-   スヌーズ操作を行うたびに、5分後に対象のアラーム通知を再度発生させる。
-   スヌーズ中も対象の通知IDを維持し、5分後の再通知では同じ通知IDを使用する。
-   スヌーズ操作時に通知音が再生中の場合は、直ちに停止する。
-   通知音を途中で停止した場合は、その時点で次に発生する通知が通知音を再生できる状態に戻す。
-   スヌーズ中も、対象通知の「終了」操作を受け付ける。
-   スヌーズ中に「終了」を操作した場合は、対象通知を完全に終了し、予約済みの再通知も取り消す。
-   ブラウザを終了した後の次回起動時には、スヌーズ状態と予約済みの再通知を復元しない。
-   スヌーズによる再通知は、スヌーズ操作時の表示位置を基本として維持する。
-   スヌーズ中にモードを切り替えても、スヌーズ操作時の表示位置を基本として維持する。
-   再通知先に同じ表示位置の通知が既に存在する場合、既存通知の順序を変更せず、再通知をその位置の一番下に追加する。
-   スヌーズ再通知時に中央表示が既に別の通知で使用されている場合、再通知を左下表示へ移す。
-   中央表示から左下表示へ移された再通知は、その後のスヌーズ再通知でも左下表示の位置を維持する。
-   スヌーズ操作と再通知は、対象以外の通知状態に影響しない。
-   スヌーズ中に同じアラームが再び発生した場合は、新しい通知IDを発行する。この場合、新しい通知とスヌーズ中の通知は別々に管理する。既存のスヌーズ状態や再通知予約には影響しない。

### 7.7 通知競合
-   タイマー通知とアラーム通知は、それぞれ独立して管理する。
-   タイマー通知とアラーム通知が同時に発生した場合、それぞれの通知を個別に表示する。
-   アラーム通知中にタイマーが終了した場合は、タイマーのカウントダウンは終了し、タイマー終了通知を発生させる。
-   タイマー動作中にアラーム時刻になった場合は、タイマーのカウントダウンを継続し、アラーム通知を発生させる。
-   片方の通知を操作しても、もう片方の通知の表示、状態、処理に影響しない。
-   モード切替時も、発生済みで操作されていない通知を引き継ぐ。
-   通知の表示位置および表示順序は、5.3～5.5の共通機能仕様に従う。
-   タイマー通知とアラーム通知の間に、通知音の優先順位は設けない。通知音を再生できるのは、先に発生した通知1件だけとする。同時に発生した場合は、先に通知処理されたものが通知音を再生する。

### 7.8 通知終了
-   アラーム通知中に終了操作を行った場合、対象の通知を終了する。
-   終了操作を行うと、対象通知の音声を停止する。
-   通知が終了しても、アラーム設定およびON/OFF状態は保持する。
-   アラームがONの場合は、翌日以降も設定時刻に通知する。
-   スヌーズ中に終了操作を行った場合は、対象通知および予約済みのスヌーズ再通知を取り消す。
-   アラーム通知に対する操作は、タイマー終了通知の表示および状態に影響を与えない。

### 7.9 削除
-   保存済みアラームを削除できる。
-   削除するアラームは、1件または複数件を選択できる。
-   ON/OFF状態にかかわらず、アラームを削除できる。
-   削除したアラームは、登録対象から除外する。
-   アラームの削除に失敗した場合は、削除を取り消し、画面上の状態を削除前に戻す。保存エラーはコンソールへ出力する。
-   削除時の保存に失敗した場合は、エラー内容をコンソールに出力する。
-   削除に失敗した場合は、対象通知の終了、通知音の停止、スヌーズ再通知予約の取消しを行わない。
-   通知中またはスヌーズ中のアラームを削除した場合は、そのアラームに紐づく通知を終了する。
-   対象アラームに予約済みのスヌーズ再通知がある場合は、それも取り消す。
-   対象アラームの通知音が再生中の場合は停止する。
-   アラームの削除は、他のアラーム通知およびタイマー終了通知に影響を与えない。

## 8. データ保存
### 8.1 保存対象
LocalStorageに以下のデータを保存する。
-   アラーム設定
   -   アラームを識別するID
   -   アラーム時刻
   -   ON/OFF状態
-   タイマー履歴
   -   履歴ID
   -   タイマー設定時間

### 8.2 保存タイミング
-   アラームを保存したときに、アラーム設定をLocalStorageへ保存する。
-   アラームのON/OFFを切り替えたときに、LocalStorageを更新する。
-   アラームを削除したときに、LocalStorageから対象アラームを削除する。
-   タイマー開始時したときに、設定時間をタイマー履歴としてLocalStorageへ保存する。
-   タイマーをキャンセルした場合も、保存済みタイマー履歴をLocalStorageに保持する。
-   保存に失敗した場合は、変更前の状態を維持し、関連する処理を実行しない。

### 8.3 復元
-   アプリケーション起動時に、LocalStorageから保存済みアラーム設定を読み込む。
-   アプリケーション起動時に、LocalStorageから保存済みタイマー履歴を読み込む。
-   保存データの読み込みに失敗した場合は、該当データを初期状態として扱う。
-   ブラウザ再起動時に復元するデータは、保存済みアラーム設定およびタイマー履歴とする。
-   動作中タイマー、通知中の状態およびスヌーズ中の状態は復元しない。

## 9. エラー処理
-   音声の再生失敗時の通知状態およびエラー出力は、4.3「音声」の仕様に従う。
-   LocalStorageに保存されたデータの読み込みに失敗した場合は、該当データを初期状態として扱う。
-   LocalStorageへの保存に失敗した場合は、4.1「データ保存」の仕様に従う。
-   アラーム削除時の保存失敗については、7.9「削除」の仕様に従う。
-   タイマー開始時の履歴保存に失敗した場合、タイマーを開始せず、開始前の状態を維持する。

| ---- | ---- |

| 表示言語 | 日本語のみとする |
| タイマー最大時間 | 23:59:59 |
| アラーム最大登録数 | 5件 |
| タイマー履歴最大保持数 | 5件 |
| アラーム重複登録 | 同じ時刻のアラームを複数登録可能とする |
| タイマー履歴重複 | 同じ時間の履歴を複数保存可能とする |
| スヌーズ時間 | 5分  |
| スヌーズ回数 | 上限なし |
| 通知音再生時間 | 最大60秒 |

| 通知音の優先 | タイマー・アラーム間に優先順位を設けず、発生順（同時の場合は通知処理順）とする |
| 通知数 | 上限なし |
| 中央表示の通知数 | 常に1件 |
| アラーム時刻の確認間隔 | 1秒ごと |
| 時刻基準 | 日本標準時（JST） |
| Undo機能 | 直前の操作や処理を取り消して元の状態に戻す機能は設けない |
