# タイマーアプリ 要求仕様
## 1. 概要
本アプリケーションは、ブラウザ上で動作するタイマーアプリである。
設定した時間をカウントダウンするタイマー機能と、指定した時刻に通知を行うアラーム機能を実行できる。
**ユーザーはタイマー機能とアラーム機能を切り替えて** 利用できる。

## 2. 対象環境

### 2.1  開発環境
-   使用言語: TypeScript
-   使用ツール: Vite, VSCode

### 2.2 動作環境
-   Google Chrome 最新版, Microsoft Edge 最新版

## 3. 機能要求

### 3.1 共通
-   タイマーモードとアラームモードを切り替えて利用できること。
-   アプリケーション起動時はタイマーモードを表示すること。
-   モード切替時も各モードの状態を保持すること。
-   タイマー終了時またはアラーム時刻到達時はユーザーへ通知すること。
-   タイマー終了時およびアラーム通知時に通知音を再生すること。
-   通知音を停止できること。
-   アラーム設定およびタイマー履歴を保存できること。
-   保存したアラーム設定およびタイマー履歴は、ブラウザを終了した後も保持できること。

### 3.2 タイマー
-   タイマー時間を設定できること。
-   時間を設定してカウントダウンできること。
-   タイマーを開始できること。
-   タイマーを一時停止および再開できること。
-   タイマーをキャンセルできること。
-   タイマー終了時に通知できること。
-   通知音を停止できること。
-   タイマー履歴を保存できること。
-   保存したタイマー履歴を再利用できること。
-   タイマー履歴を最大5件保持できること。

### 3.3 アラーム
-   アラーム時刻を設定できること。
-   時間・分をスクロール操作で入力できること。
-   アラーム時刻は00:00～23:59の範囲で設定できること。
-   設定したアラームを保存できること。
-   保存したアラームをON/OFF切り替えできること。
-   ON状態のアラームは設定時刻に通知できること。
-   スヌーズ機能を利用できること。
-   保存したアラームを削除できること。
-   アラームは最大5件登録できること。
-   保存したアラームはブラウザ終了後も保持できること。
-   アラームは毎日同じ時刻に通知すること。
-   過去のアラーム時刻に遡って通知することはない。

## 4. 非機能要求

### 4.1 データ保存
-   アラーム設定およびタイマー履歴は、ブラウザ終了後も保持されること。

### 4.2 時刻
-   アラームの時刻判定は**日本標準時（JST）**を基準とする。

## 5. 制約事項
| 項目 | 内容 |
| ---- | ---- |
| 入力方法 | ボタン操作およびスクロール操作のみに限定する |
| 重複登録 | 同一時刻のアラームを複数登録可能とする  |
| 表示言語 | 日本語のみとする |
| Undo機能 | 直前に行った操作や処理を取り消し、元の状態に戻すアンドゥー機能は考慮しない |


# タイマーアプリ 機能仕様
## 1. 概要
本書ではタイマーアプリの機能仕様を定義する。
要件定義で定めた機能要求に基づき、各機能の動作仕様を定義する。

## 2. 共通機能

### 2.1 モード切替
-   タイマー状態とアラーム状態は独立して管理する。
-   タイマー画面とアラーム画面を切り替えできる。
-   タイマー動作中にアラーム画面へ切り替えた場合、タイマーの動作状態を保持する。
-   タイマーが一時停止中にアラーム画面へ切り替えた場合、一時停止状態を保持する。
-   アラーム画面からタイマー画面へ切り替えた場合、タイマーの状態を保持する。
-   保存済みアラーム設定は、モードを切り替えても保持する。

#### 2.2 通知
-   タイマー終了時またはアラーム時刻到達時はアラートを通知する。
-   アラート終了操作は、アラート表示中のみ受け付ける。
-   アラート終了操作により、アラート音を停止し通知を終了する。
-   アラート音は60秒間再生する。

### 2.3 音声
-   音声がミュート状態または音量が0の場合でも、音声再生処理は実行する。

### 2.4 状態保持
-   保存済みのアラーム設定は保持する。

### 2.5 ブラウザ終了・再起動
-   ブラウザ起動中のみタイマーおよびアラーム機能を動作させる。
-   アラーム時刻経過後にブラウザを起動した場合、アラーム通知は行わない。

## 3. タイマー機能

### 3.1 時間設定
-   タイマー設定時間の**初期値は「00:00:00」**とする。
-   入力可能な範囲は、**時間(0～23)、分(0～59)、秒(0～59)**とする。
-   設定した時間をタイマー表示エリアへ反映する。
-   タイマー設定値が「00:00:00」の場合、**開始操作を受け付けない**。
-   タイマー設定時間が00:00:00以外となった場合、開始ボタンを有効状態とする。

### 3.2 開始
-   開始ボタン押下後は、スクロール操作を受け付けない。
-   タイマー開始後、設定時間からカウントダウンを開始する。

### 3.3 カウントダウン
-   カウントダウン中は、タイマー時間を変更できない。
-   開始ボタンを無効状態とする。
-   アラーム画面へ切り替えた場合も、タイマーのカウントダウンを継続する。
-   ブラウザを終了した場合、カウントダウン中の状態は破棄する。
-   ブラウザを再度起動した場合は、初期状態で表示する。
-   残時間を1秒ごとに更新する。
-   残時間が「00:00:00」となった場合は、カウントダウンを終了する。

### 3.4 一時停止・再開
-   一時停止ボタン押下後は、一時停止ボタンを再開ボタンへ切り替える。
-   カウントダウン停止中は、再開ボタンおよびキャンセルボタンのみ押下可能とする。
-   アラーム画面へ切り替えた場合も、一時停止状態を維持する。
-   ブラウザを終了した場合、一時停止中の状態は破棄する。
-   ブラウザを再度起動した場合は、初期状態で表示する。
-   カウントダウン中は、一時停止操作を受け付ける。
-   一時停止操作を行った場合、残時間を保持したままカウントダウンを停止する。
-   再開操作を行った場合、停止時点の残時間からカウントダウンを再開する。
-   カウントダウン中および一時停止中は、キャンセル操作を受け付ける。
-   再開ボタン押下後に一時停止ボタンへ切り替わる。
-   カウントダウン再開後は、一時停止ボタンおよびキャンセルボタンのみ押下可能とする。
-   一時停止時点の残時間からカウントダウンを再開する。
-   アラーム画面へ切り替えた場合も、カウントダウンを継続する。

### 3.5 キャンセル
-   キャンセル確認画面表示中はカウントダウンが一時停止状態となる。
-   キャンセル確認画面表示中は、「はい」「いいえ」のみ押下可能とする。
-   「はい」押下後に初期画面（00:00:00）へ戻り事前に設定したタイマー時刻は破棄される（履歴にも反映されない）

### 3.6 終了通知
-   アラート終了ボタン表示中は、アラート終了ボタン以外の操作を受け付けない。（アラームの切り替えも不可）
-   タイマーの残時間が00:00:00となった場合、通知音を再生する。
-   通知音の再生時間は60秒とする。
-   アラート終了ボタンを押下した場合は、通知音の再生を停止する。
-   アラート終了ボタン表示中にブラウザ画面を閉じた場合は、アラート終了ボタンを押下できていない状態として、時刻設定前の初期画面（00:00:00）へ戻る。

### 3.7 履歴保存
-   履歴はボタンとして表示する。
-   履歴は最大5件保持する。
-   新しい履歴を先頭へ追加する。
-   既存の履歴は1件ずつ下へ移動する。
-   5件を超えた場合は最も古い履歴を削除する。
-   タイマー終了時、タイマー開始時に設定した時間を履歴として保存する
-   アラート終了ボタンを押下した場合のみ保存する。
-   キャンセルしたタイマーは履歴に保存しない。
-   履歴の重複は許可する。
-   履歴ボタン押下後はタイマー開始待ち状態とする。

### 3.8 履歴再利用
-   履歴に表示した時刻は、再利用するためのボタンとして機能する。
-   同時に選択できる履歴ボタンは1件のみとする。
-   選択中の履歴ボタンは1件のみ保持する。
-   他の履歴ボタンを押下した場合は、前回選択した履歴ボタンの選択を解除し、新しく押下した履歴ボタンを選択状態とする。
-   選択した履歴ボタンの時間をタイマー設定時間へ反映する。
-   選択中の履歴ボタンを再度押下した場合は、選択状態を解除する。
-   選択状態を解除した場合は、タイマー設定時間を初期状態（00:00:00）へ戻す。
-   タイマー設定時間が00:00:00以外の場合は、開始ボタンを有効状態とする。
-   履歴ボタンを押下した場合、その時間をタイマー設定時間へ反映する。

### 3.9 ブラウザ終了時の動作
-   ブラウザを閉じたらタイマーを終了する。

## 4. アラーム機能

### 4.1 アラーム登録
-   アラームを登録できる。
-   アラームは**最大5件まで登録**できる。
-   登録件数が5件に達している場合は、新たなアラームを登録できない。

### 4.2 時刻設定
-   アプリ起動時はタイマー画面を表示する。
-   アラーム切替ボタン押下時にアラーム画面へ切り替える。
-   アラーム設定時刻の**初期値は「00:00」**とする。
-   追加ボタン押下後、新規アラームの設定状態へ切り替える。
-   設定ボタン押下後、時刻設定操作を可能とする。
-   時間（0～23）、分（0～59）をスクロール操作で設定できる。
-   設定した時刻をアラーム設定時刻として表示する。
-   「00:00」は有効なアラーム設定時刻として扱う。
-   保存前にブラウザを終了した場合、設定中のアラーム時刻は破棄する。
-   保存済みアラーム設定はブラウザ再起動後も表示する。
-   アラームは最大5件まで登録できる。

### 4.3 保存
-   保存ボタン押下後、設定したアラームをアラーム一覧へ追加する。
-   保存完了後、時刻設定状態を終了し、追加ボタン表示へ戻る。
-   保存したアラーム設定は一覧に表示する。
-   保存したアラームは初期状態をONとする。
-   保存したアラーム設定はLocalStorageへ保存する。
-   保存前にブラウザを終了した場合、設定中のアラーム時刻は保存しない。
-   **初期値「00:00」の状態でも保存可能**とする。
-   保存したアラームは通知後も保持する。

### 4.4 ON/OFF
-   保存済みアラームは最大5件まで保持する。
-   保存したアラームはON/OFFを切り替えできる。
-   保存直後のアラーム状態はONとする。
-   ON状態のアラームは設定時刻に通知する。
-   OFF状態のアラームは、設定時刻に到達しても通知しない。
-   ON/OFF状態の変更は保存する。
-   保存済みアラームが5件の場合、新規追加操作を無効状態とする。

### 4.5 通知
-   アラート画面表示と同時にアラーム音を再生する。
-   アラーム音は60秒間再生する。
-   アラーム音の再生終了後も終了ボタン押下までアラート画面を表示する。
-   同時刻に複数のアラームが通知対象となった場合は、最初に保存した（通知されている）アラームを優先する。
-   優先されなかったアラームは通知しない。
-   アラート表示中は、スヌーズ操作および終了操作以外を受け付けない。
-   **ON状態のアラーム**は、設定時刻に到達した場合にアラートを通知する。
-   アラーム時刻は、**日本標準時刻**基準として判定する。

### 4.6 スヌーズ
-   スヌーズ操作を行った場合、設定したスヌーズ時間後に再度通知する。
-   スヌーズ中も元のアラーム設定は保持する。
-   スヌーズ開始後、5分間のスヌーズタイマーを開始する。
-   スヌーズ時間経過後、再度アラート画面を表示しアラーム音を再生する。
-   スヌーズは複数回利用できる。
-   スヌーズ操作を行うたびに、5分後に再度通知する。
-   スヌーズ回数に上限を設けない。
-   スヌーズ中は、終了操作のみ受け付ける。
-   スヌーズ中は、以下の操作を無効とする。
    -   タイマー画面への切替
    -   アラームON/OFF切替
    -   アラーム削除
    -   新規アラーム設定
-   スヌーズ中に終了ボタンを押下した場合、スヌーズを終了する。
-   スヌーズ中に終了ボタンを押下した場合、アラーム音の再生を停止する。
-   スヌーズ終了後も、元のアラーム設定およびON/OFF状態は保持する。
-   スヌーズ中にブラウザを終了した場合、スヌーズ状態は破棄する。
-   ブラウザ再起動後は初期状態で表示する。
-   スヌーズ中にタイマーが終了した場合、タイマー側のアラート通知は行わない。
-   終了ボタン押下時はスヌーズを停止する。
-   スヌーズ終了後も元のアラーム設定は保持する。
-   アラーム通知中またはスヌーズ中にタイマーが終了した場合、タイマーのカウントダウンは終了する。
-   タイマー終了通知は行わない。
-   アラーム通知中にスヌーズ操作を受け付ける。
-   アラート終了操作を行った場合はスヌーズを停止する。

### 4.7 通知終了
-   アラート表示中は、スヌーズボタンおよび終了ボタン以外の操作を受け付けない。
-   終了ボタン押下時は、アラーム音の再生を停止する。
-   アラーム音の再生終了後も、アラート画面は終了ボタンが押下されるまで表示する。
-   終了後もアラーム設定およびON/OFF状態は保持する。
-   終了後も翌日以降、設定時刻に再度通知する。
-   スヌーズ中に終了ボタンを押下した場合、スヌーズを終了する。
-   アラート表示中にブラウザを終了した場合、アラート状態を破棄する。
-   ブラウザを再起動した場合は、通常のアラーム画面を表示する。
-   ブラウザ終了時は、当日の通知状態およびスヌーズ状態を保持しない。
-   アラーム通知中にタイマーが動作している場合、タイマーのカウントダウンは継続する。
-   アラーム通知中にタイマーが終了した場合、タイマー終了通知は行わない。

### 4.8 削除
-   アラーム一覧の時刻を押下すると削除対象として選択する。
-   複数のアラームを同時に選択できる。
-   選択したアラームは青色で表示する。
-   選択済みのアラームを再度押下した場合、選択を解除する。
-   削除ボタン押下時、選択したアラームを削除する。
-   ON/OFF状態にかかわらず、選択したアラームを削除できる。
-   複数のアラームを同時に削除できる。
-   削除したアラームはアラーム一覧から削除する。
-   削除したアラームはLocalStorageから削除する。
-   削除後は選択状態を解除する。

## 5. データ保存
-   アラーム設定はLocalStorageへ保存する。
-   削除時はLocalStorageから削除する。
-   タイマー履歴はLocalStorageへ保存する。
-   タイマー履歴は5件を超えた場合は最も古い履歴を削除する。

## 6. エラー処理
-   音声の再生に失敗した場合は、エラー内容をコンソールへ出力する。

# タイマーアプリ 画面仕様（別シート参照）
## 1. 概要
本書ではタイマーアプリの画面仕様を定義する。画面デザインの詳細については別シートを参照する。

## 2. 共通レイアウト
-   タイマー／アラーム切り替えボタンを配置する。
-   時間設定部にはスクロール操作用のUIを配置する。
-   タイマーおよびアラームの設定値は、各項目を**2桁で表示**する(例：01:30:45、00:05)。
-   表示エリアには設定時間または残時間を表示する。
-   ボタンの配置およびサイズはデザイン資料に従う。
-   ボタンのラベルは日本語で表示する。
-   ボタンの表示文は本書で定義した名称を使用する。
-   **アラーム有効／無効切り替えボタンは「ON」「OFF」で表示**とする。
-   無効状態のボタンは灰色で表示し、押下できない状態とする。
-   アラート画面には終了ボタンを配置する。

## 3. タイマー画面

### 3.1 レイアウト
-   タイマー時間設定をスクロール操作で選択する入力UIを配置する。
-   タイマー開始ボタンを配置する。
-   タイマー残時間表示エリアを配置する。
-   タイマー一時停止／再開ボタンを配置する。
-   タイマーキャンセルボタンを配置する。
-   タイマー履歴表示エリア（最大5件）を配置する。
-   タイマー履歴ボタン（最大5件）を配置する。

### 3.2 時間設定
-   タイマー時間設定中は、時間設定用スクロール操作およびモード切替操作以外を受け付けない。
-   タイマー残時間表示エリアを配置する。
-   時間・分・秒をスクロール操作で選択する入力UIを配置する
-   アラーム切替ボタンを配置する。
-   押下できないボタンは灰色表示とする。
-   タイマー設定時間が未設定状態と設定済み状態で視覚的に区別できること。

### 3.3 開始ボタン
-   開始ボタンを配置する。
-   開始ボタンは有効状態および無効状態を表示できること。
-   タイマー設定時間が00:00:00の場合、開始ボタンを無効表示する。
-   タイマー開始後、表示エリアに残時間を表示する。
-   無効状態では灰色で表示する。

### 3.4 残時間表示
-   タイマーの残時間を表示エリアへ表示する。

### 3.5 一時停止/再開
-   一時停止／再開ボタンを配置する。
-   カウントダウン中は「一時停止」を表示する。
-   一時停止中は「再開」を表示する。
-   利用できない状態では灰色表示とする。

### 3.6 キャンセル確認
-   キャンセルボタンを配置する。
-   キャンセル確認画面を表示する。
-   キャンセル確認画面に「はい」「いいえ」ボタンを配置する。
-   カウントダウン中および一時停止中に表示する。

### 3.7 履歴
-   保存済みのタイマー時間を一覧表示する。
-   タイマー履歴ボタンを最大5件表示する。
-   履歴が存在しない場合は一覧を表示しない。
-   選択中の履歴ボタンは青色で表示する。
-   未選択の履歴ボタンは通常色で表示する。
-   同時に選択状態となる履歴ボタンは1件のみとする。

## 4. アラーム画面

### 4.1 レイアウト
-   アラーム時刻表示エリアを配置する。
-   時間・分をスクロール操作で選択する入力UIを配置する。
-   アラーム追加ボタンを配置する。
-   アラーム保存ボタンを配置する。
-   アラーム一覧（最大5件）を配置する。
-   アラームごとにON/OFF切替ボタンを配置する。
-   アラーム削除ボタンを配置する。

### 4.2 時刻設定
-   アラーム時刻設定をスクロール操作で選択する入力UIを配置する。
-   初期表示は「00:00」とする。
-   時間（0〜23）、分（0〜59）をスクロール操作で選択する入力UIを配置する。
-   設定した時刻を表示エリアに反映する。

### 4.3 追加
-   時刻設定エリアを配置する。
-   保存ボタンを配置する。
-   保存完了後、時刻設定表示を初期状態「00:00」へ戻す。
-   保存完了後、追加ボタンを表示する。
-   アラーム追加ボタンを配置する。
-   登録件数が5件の場合、追加ボタンを無効表示とする。

### 4.4 保存
-   アラーム保存ボタンを配置する。

### 4.5 アラーム一覧
-   保存済みアラームを一覧表示する。
-   選択したアラームは青色で表示する。
-   複数選択できる。

### 4.6 ON/OFF
-   アラーム時刻部分を押下した場合、削除対象の選択状態を切り替える。
-   ON/OFFボタンを押下した場合、ON/OFF状態のみを切り替える。
-   ON/OFFボタンの操作では削除対象の選択状態を変更しない。

### 4.7 削除
-   アラーム削除ボタンを配置する。
-   1件以上選択した場合のみ押下可能とする。

## 5. アラート画面

### 5.1 共通
-   アラートメッセージを表示する。
-   アラート終了ボタンを配置する。

### 5.2 タイマー終了
-   タイマー終了を示すメッセージを表示する。

### 5.3 アラーム通知
-   アラーム通知を示すメッセージを表示する。

### 5.4 スヌーズ
-   スヌーズ中であることを示すメッセージを表示する。
-   スヌーズ中は終了ボタンを配置する。
-   スヌーズ中はスヌーズ残時間を表示する
