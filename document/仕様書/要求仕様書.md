# タイマー・アラームアプリ 要求仕様
## 1. 概要
本アプリケーションは、ブラウザ上で動作するタイマー・アラームアプリケーションである。
設定した時間をカウントダウンするタイマー機能と、指定した時刻に通知を行うアラーム機能を実行できる。
**ユーザーはタイマー機能とアラーム機能を切り替えて** 利用できる。

## 2. 対象環境

### 2.1  開発環境
-   使用言語: TypeScript
-   使用ツール: Vite, VSCode

### 2.2 動作環境
-   Google Chrome 最新版, Microsoft Edge 最新版

## 3. 機能要求

### 3.1 共通
-   タイマーモードとアラームモードを切り替えて利用できること。
-   アプリケーション起動時はタイマーモードを表示すること。
-   タイマー状態とアラーム状態を独立して管理できること。
-   モード切替時も各モードの状態を保持すること。
-   タイマー終了時またはアラーム時刻到達時はユーザーへ通知すること。
-   タイマー終了時およびアラーム通知時に通知音を再生すること。
-   通知音を停止できること。
-   通知音の再生時間は60秒とする。  

### 3.2 タイマー
-   タイマー時間を設定できること。
-   タイマー時間は、時間・分・秒を設定できること。
-   タイマー時間の設定範囲は、00:00:00～23:59:59とする。
-   タイマーを開始できること。
-   タイマー開始後、設定時間からカウントダウンできること。
-   タイマーを一時停止および再開できること。
-   タイマーをキャンセルできること。
-   タイマー終了時に通知できること。
-   タイマー終了時に通知音を再生できること。
-   通知音を停止できること。
-   タイマー履歴を保存できること。
-   保存したタイマー履歴を再利用できること。
-   タイマー履歴を最大5件保持できること。
-   同一時間のタイマー履歴を複数保存できること。

### 3.3 アラーム
-   アラーム時刻を設定できること。
-   アラーム時刻は、時間・分を設定できること。
-   アラーム時刻は00:00～23:59の範囲で設定できること。
-   00:00を有効なアラーム時刻として登録できること。
-   設定したアラームを保存できること。
-   保存したアラームをON/OFF切り替えできること。
-   ON状態のアラームは設定時刻に通知できること。
-   OFF状態のアラームは、設定時刻に通知しないこと。
-   アラーム通知時に通知音を再生できること。
-   アラーム通知中にスヌーズを利用できること。
-   保存したアラームを削除できること。
-   アラームは最大5件登録できること。
-   同一時刻のアラームを複数登録できること。
-   保存したアラーム設定はブラウザ終了後も保持できること。
-   アラームは毎日同じ時刻に通知すること。
-   過去のアラーム時刻に遡って通知することはない。

## 4. 非機能要求

### 4.1 データ保存
-   アラーム設定およびタイマー履歴は、ブラウザ終了後も保持する。
-   アラーム設定およびタイマー履歴はLocalStorageに保存する。
-   LocalStorageから保存データを読み込めない場合は、該当データを初期状態として扱う。

### 4.2 時刻
-   アラームの時刻判定は**日本標準時（JST）**を基準とする。
-   アラームの時刻判定には現在時刻を使用する。
-   ブラウザまたは端末の停止・スリープ等により設定時刻を経過した場合、復帰後に過去の時刻に遡って通知しない。

### 4.3 音声
-   タイマー終了時およびアラーム通知時に通知音を再生する。
-   通知音の再生時間は60秒とする。
-   通知終了操作により通知音を停止できる。
-   アプリケーション内で管理する音量が0の場合でも、音声再生処理自体は実行する。
-   音声の再生に失敗した場合は、エラー内容をコンソールへ出力する。

## 5. 共通機能仕様

### 5.1 モード切替
-   タイマー画面とアラーム画面を切り替えできる。
-   タイマー状態とアラーム状態は独立して管理する。
-   タイマー動作中にアラーム画面へ切り替えた場合、タイマーの動作状態を保持する。
-   タイマーが一時停止中にアラーム画面へ切り替えた場合、一時停止状態を保持する。
-   アラーム画面からタイマー画面へ切り替えた場合、タイマーの状態を保持する。
-   保存済みアラーム設定は、モードを切り替えても保持する。
-   アプリケーション起動時はタイマー画面を表示する。

#### 5.2 通知
-   タイマー終了時またはアラーム時刻到達時にアラートを表示する。
-   アラート表示中は、定義された通知操作以外を受け付けない。
-   アラート終了操作は、アラート表示中のみ受け付ける。
-   アラート終了操作により、アラート音を停止し通知を終了する。
-   アラート音は60秒間再生する。
-   アラート音の再生が終了した場合でも、終了操作が行われるまでアラート状態を維持する。

### 5.3 ブラウザ終了・再起動
-   ブラウザ起動中のみ、タイマーおよびアラーム機能を動作させる。
-   ブラウザ終了時、動作中のタイマー状態を破棄する。
-   ブラウザ終了時、タイマーの一時停止状態を破棄する。
-   ブラウザ終了時、アラームの通知状態を破棄する。
-   ブラウザ終了時、アラームのスヌーズ状態を破棄する。
-   ブラウザ終了時、設定中で保存されていないアラーム時刻を破棄する。
-   ブラウザ再起動時は、保存済みのアラーム設定およびタイマー履歴を復元する。
-   ブラウザ再起動時、タイマーは初期状態とする。
-   ブラウザ再起動時、通知中またはスヌーズ中の状態は復元しない。

## 6. タイマー機能仕様

### 6.1 時間設定
-   タイマー設定時間の**初期値は「00:00:00」**とする。
-   入力可能な範囲は、**時間(0～23)、分(0～59)、秒(0～59)**とする。
-   タイマー設定時間の最大値は23:59:59とする。
-   設定した時間をタイマーに設定する。
-   00:00:00の場合、**開始操作を受け付けない**。
-   00:00:00以外の場合、タイマーを開始できる。
-   設定した時間をタイマー設定値として保持する。

### 6.2 開始
-   タイマー開始後、設定時間からカウントダウンを開始する。
-   タイマー開始後は、設定時間を変更できない。
-   タイマー開始後は、時間設定用の入力操作を受け付けない。
-   タイマー開始後、設定時間からカウントダウンする。
-   アラーム画面へ切り替えた場合も、タイマーのカウントダウンを継続する。

### 6.3 カウントダウン
-   タイマーの残時間は、現在時刻と終了予定時刻との差分から算出する。
    -   終了予定時刻 = 開始時刻 + 設定時間
    -   残時間 = 終了予定時刻 - 現在時刻
-   残時間が00:00:00となった場合、カウントダウンを終了する。
-   ブラウザを終了した場合、カウントダウン中のタイマー状態を破棄する。
-   開始ボタンを無効状態とする。

### 6.4 一時停止・再開
-   カウントダウン中は、一時停止操作を受け付ける。
-   一時停止操作を行った場合、一時停止時点の残時間を秒単位で保持する。
-   一時停止中はカウントダウンを停止する。
-   再開操作を行った場合、保持している残時間からカウントダウンを再開する。
-   再開後は、再度一時停止操作を受け付ける。
-   カウントダウン中および一時停止中は、キャンセル操作を受け付ける。
-   アラーム画面へ切り替えた場合も、一時停止状態を維持する。
-   ブラウザを終了した場合、一時停止状態を破棄する。

### 6.5 キャンセル
-   カウントダウン中または一時停止中にタイマーをキャンセルできる。
-   キャンセル操作時は、キャンセル確認を行う。
-   キャンセル確認中は、タイマーのカウントダウンを一時停止する。
-   「はい」を選択した場合、タイマーをキャンセルする。
-   キャンセルしたタイマーの設定時間および残時間を破棄する。
-   キャンセルしたタイマーは履歴に保存しない。
-   「いいえ」を選択した場合、キャンセル確認前の状態へ戻る。
-   キャンセル確認前がカウントダウン中の場合は、カウントダウンを再開する。
-   キャンセル確認前が一時停止中の場合は、一時停止状態へ戻る。

### 6.6 終了通知
-   タイマーの残時間が00:00:00となった場合、タイマーを終了する。
-   タイマー終了時にアラートを表示する。
-   タイマー終了時に通知音を再生する。
-   通知音は最大60秒間再生する。
-   アラート表示中は、終了操作のみ受け付ける。
-   アラート終了操作により、通知音を停止する。
-   アラート終了操作により、タイマー終了通知を終了する。
-   タイマー終了後、通知終了操作を行うまでタイマー履歴を保存しない。
-   アラート表示中にブラウザを終了した場合、当該タイマー履歴を保存しない。
-   ブラウザ再起動後は、タイマーを初期状態00:00:00とする。

### 6.7 履歴保存
-   タイマー終了後、通知終了操作を行ったタイミングでタイマー履歴を保存する。
-   保存する履歴は、タイマー終了時の設定時間とする。
-   タイマー履歴は最大5件保持する。
-   6件目の履歴を保存する場合、最も古い履歴を削除する。
-   新しい履歴を一覧の先頭に追加する。
-   同一時間の履歴を複数保存できる。
-   キャンセルしたタイマーは履歴に保存しない。
-   通知終了操作を行わずブラウザを終了した場合、履歴を保存しない。
-   タイマー履歴はLocalStorageに保存する。
-   タイマー履歴が存在しない場合、履歴一覧を表示しない。

### 6.8 履歴再利用
-   保存したタイマー履歴を選択して再利用できる。
-   履歴を選択した場合、履歴に保存されている時間をタイマー設定時間へ反映する。
-   履歴を再利用した場合、タイマーは開始待ち状態とする。
-   選択できる履歴は1件のみとする。
-   別の履歴を選択した場合、以前の選択を解除し、新しく選択した履歴を選択状態とする。
-   選択中の履歴を再度選択した場合、選択状態を解除する。
-   履歴の選択を解除した場合、タイマー設定時間を00:00:00へ戻す。
-   タイマー設定時間が00:00:00以外の場合、タイマーを開始できる。

## 7. アラーム機能仕様

### 7.1 アラーム登録
-   アラームを登録できる。
-   アラームは**最大5件まで登録**できる。
-   登録件数が5件の場合、新たなアラームを登録できない。
-   同一時刻のアラームを複数登録できる。

### 7.2 時刻設定
-   アラーム設定時刻の**初期値は「00:00」**とする。
-   入力可能な範囲は、**時間(0～23)、分(0～59)**とする。
-   00:00は有効なアラーム設定時刻として扱う。
-   設定中のアラームは、保存するまで登録済みアラームとして扱わない。
-   保存前にブラウザを終了した場合、設定中のアラーム時刻を破棄する。

### 7.3 保存
-   設定したアラームを保存できる。
-   00:00の状態でも保存できる。
-   保存したアラームはアラーム一覧に追加する。
-   保存直後のアラーム状態はONとする。
-   保存したアラーム設定はLocalStorageへ保存する。
-   保存したアラームは、通知後も保持する。
-   保存したアラームは、翌日以降も同じ時刻に通知する。

### 7.4 ON/OFF
-   保存したアラームはON/OFFを切り替えできる。
-   ON状態のアラームは、設定時刻に通知する。
-   OFF状態のアラームは、設定時刻に到達しても通知しない。
-   ON/OFF状態の変更は保存する。
-   アラームを削除していない限り、ON/OFF状態を保持する。

### 7.5 通知
-   ON状態のアラームが設定時刻に到達した場合、アラートを表示する。
-   アラート表示と同時にアラーム音を再生する。
-   アラーム音は最大60秒間再生する。
-   アラーム音の再生終了後も、終了操作が行われるまでアラート状態を維持する。
-   アラート表示中は、終了操作およびスヌーズ操作のみ受け付ける。
-   終了操作を行った場合、アラーム音を停止し、アラートを終了する。
-   アラーム終了後も、アラーム設定およびON/OFF状態を保持する。
-   アラームは翌日以降も設定時刻に通知する。
-   アラーム時刻の判定はJSTを基準とする。
-   過去の時刻に遡って通知しない。
-   同一時刻に複数のON状態アラームが通知対象となった場合、最初に保存したアラームを通知対象とする。
-   同時刻に通知対象となったその他のアラームは、その日の通知を行わない。
-   翌日以降は、各アラームを通常どおり通知対象とする。

### 7.6 スヌーズ
-   アラーム通知中にスヌーズ操作を行える。
-   スヌーズ操作を行った場合、アラーム通知を一時停止し、5分間のスヌーズ状態とする。
-   スヌーズ残時間を表示する。
-   スヌーズ時間は5分とする。
-   スヌーズ時間経過後、再度アラートを表示し、アラーム音を再生する。
-   スヌーズは複数回利用できる。
-   スヌーズ回数に上限を設けない。
-   スヌーズ操作を行うたびに、5分後に再度通知する。
-   スヌーズ中は終了操作のみ受け付ける。

-   スヌーズ中は、以下の操作を受け付けない。
    -   タイマー／アラームのモード切替
    -   アラームON/OFF変更
    -   アラーム削除
    -   新規アラーム設定
-   スヌーズ中にブラウザを終了した場合、スヌーズ状態を破棄する。
-   ブラウザ再起動後、スヌーズ状態を復元しない。

### 7.7 通知競合
-   タイマー通知とアラーム通知が同時に発生した場合、アラーム通知を優先する。
-   アラーム通知中にタイマーが終了した場合、タイマーのカウントダウンは終了する。
-   アラーム通知中にタイマーが終了した場合、タイマー終了通知は行わない。
-   アラーム通知中にタイマーが動作している場合、タイマーのカウントダウンは継続する。
-   タイマー通知中にアラーム時刻へ到達した場合、アラーム通知を優先する。

### 7.8 通知終了
-   アラーム通知中に終了操作を行った場合、アラーム通知を終了する。
-   終了操作によりアラーム音を停止する。
-   終了後もアラーム設定およびON/OFF状態は保持する。
-   通知終了後も、翌日以降の通知を継続する。

-   スヌーズ中に終了操作を行った場合、アラーム音を停止する。
-   アラート表示中にブラウザを終了した場合、アラート状態およびスヌーズ状態を破棄する。
-   ブラウザ終了後に再起動した場合、通常のアラーム状態から開始する。

### 7.9 削除
-   保存済みアラームを削除できる。
-   削除対象のアラームを1件以上選択した場合、削除できる。
-   ON/OFF状態にかかわらず、アラームを削除できる。
-   複数のアラームを同時に削除できる。
-   削除したアラームはアラーム一覧から削除する。
-   削除したアラームはLocalStorageから削除する。
-   削除後は選択状態を解除する。

## 8. データ保存

### 8.1 保存対象
LocalStorageに以下のデータを保存する。
-   アラーム設定
   -   アラーム時刻
   -   ON/OFF状態
-   タイマー履歴
   -   タイマー設定時間

### 8.2 保存タイミング
-   アラームを保存した時点で、アラーム設定をLocalStorageへ保存する。
-   アラームのON/OFF状態を変更した時点で、LocalStorageを更新する。
-   アラームを削除した時点で、LocalStorageから対象アラームを削除する。
-   タイマー終了後、通知終了操作を行った時点でタイマー履歴をLocalStorageへ保存する。

### 8.3 復元
-   アプリケーション起動時にLocalStorageから保存済みアラーム設定を読み込む。
-   アプリケーション起動時にLocalStorageから保存済みタイマー履歴を読み込む。
-   保存データの読み込みに失敗した場合は、該当データを初期状態として扱う。

## 9. エラー処理
-   音声の再生に失敗した場合は、エラー内容をコンソールへ出力する。
-   LocalStorageに保存されたデータの読み込みに失敗した場合は、該当データを初期状態として扱う。
-   LocalStorageへの保存に失敗した場合は、エラー内容をコンソールへ出力する。

## 10. 制約事項
| 項目 | 内容 |
| ---- | ---- |
| 入力方法 | ボタン操作およびスクロール操作のみに限定する |
| 表示言語 | 日本語のみとする |
| タイマー最大時間 | 23:59:59 |
| アラーム最大登録数 | 5件 |
| タイマー履歴最大保持数 | 5件 |
| アラーム重複登録 | 同一時刻のアラームを複数登録可能とする |
| タイマー履歴重複 | 同一時間の履歴を複数保存可能とする |
| スヌーズ時間 | 5分  |
| スヌーズ回数 | 上限なし |
| 通知音再生時間 | 最大60秒 |
| 時刻基準 | 日本標準時（JST） |
| Undo機能 | 直前に行った操作や処理を取り消し、元の状態に戻すアンドゥー機能は考慮しない |
