# タイマーアプリ 要求仕様
## 1. 概要

本アプリケーションは、ブラウザ上で動作するタイマーアプリである。
設定した時間をカウントダウンするタイマー機能と、指定した時刻に通知を行うアラーム機能を実行できる。
**ユーザーはタイマー機能とアラーム機能を切り替えて** 利用できる。

## 2. 対象環境

### 2.1  開発環境
-   使用言語: TypeScript
-   使用ツール: Vite, VSCode

### 2.2 動作環境
-   Google Chrome 最新版, Microsoft Edge 最新版

## 3. 機能要求

### 3.1 共通
-   タイマーモードとアラームモードを切り替えて利用できること。
-   アプリケーション起動時はタイマーモードを表示すること。
-   モード切替時も各モードの状態を保持すること。
-   タイマー終了時またはアラーム時刻到達時はユーザーへ通知すること。
-   タイマー終了時およびアラーム通知時に通知音を再生すること。
-   通知音を停止できること。
-   アラーム設定およびタイマー履歴を保存できること。
-   保存したアラーム設定およびタイマー履歴は、ブラウザを終了した後も保持できること。

### 3.2 タイマー
-   タイマー時間を設定できること。
-   時間を設定してカウントダウンできること。
-   タイマーを開始できること。
-   タイマーを一時停止および再開できること。
-   タイマーをキャンセルできること。
-   タイマー終了時に通知できること。
-   通知音を停止できること。
-   タイマー履歴を保存できること。
-   保存したタイマー履歴を再利用できること。
-   タイマー履歴を最大5件保持できること。

### 3.3 アラーム
-   指定時刻に通知できること。
-   登録・削除できること。
-   ON/OFF切替できること。
-   最大5件登録できること。
-   スヌーズ機能を利用できること。
-   スヌーズ間隔を設定できること。

## 4. 非機能要求

### 4.1 データ保存
-   アラーム設定をLocalStorageへ保存すること。
-   タイマー履歴をLocalStorageへ保存すること。

### 4.2 時刻
-   **日本標準時刻**を基準として時刻を判定すること。

## 5. 制約事項
| 項目 | 内容 |
| ---- | ---- |
| 入力方法 | ボタン操作およびスクロール操作のみに限定する |
| 重複登録 | 同一時刻のアラームを複数登録可能とする  |
| 表示言語 | 日本語のみとする |
| Undo機能 | 直前に行った操作や処理を取り消し、元の状態に戻すアンドゥー機能は考慮しない |


# タイマーアプリ 機能仕様
## 1. 概要

本書ではタイマーアプリの機能仕様を定義する。
要件定義で定めた機能要求に基づき、各機能の動作仕様を定義する。

## 2. 機能仕様

### 2.1 共通機能
-   タイマー終了時またはアラーム時刻到達時はアラートを通知する。
-   アラート音は10秒間再生する。
-   アラート終了操作は、アラート表示中のみ受け付ける。
-   アラート終了操作により、アラート音を停止し通知を終了する。
-   音声がミュート状態または音量が0の場合でも、音声再生処理は実行する。
-   ブラウザ起動中のみタイマーおよびアラーム機能を動作させる。
-   アラーム時刻経過後にブラウザを起動した場合、アラーム通知は行わない。
-   保存済みのアラーム設定は保持する。

### 2.2 タイマー機能

#### 2.2.1 時間設定
-   タイマー残時間以外のボタンは押下できない。
-   ブラウザを閉じたらタイマーを終了する。
-   設定した時間をタイマー表示エリアへ反映する。
-   タイマー設定時間の**初期値は「00:00:00」**とする。
-   入力可能な範囲は、**時間(0～23)、分(0～59)、秒(0～59)**とする。
-   タイマー設定値が「00:00:00」の場合、**開始操作を受け付けない**。
-   タイマー設定時間が00:00:00以外となった場合、開始ボタンを有効状態とする。

#### 2.2.2 タイマー開始
-   タイマー設定時間が00:00:00の場合、開始ボタンは無効状態とする。
-   タイマー設定時間が00:00:00以外となった場合、開始ボタンを有効状態とする。
-   開始ボタン押下後は、スクロール操作を受け付けない。
-   開始ボタン押下後は、タイマー表示エリアを残時間表示へ切り替える。
-   開始ボタン押下後は、設定した時間からカウントダウンを開始する。

#### 2.2.3 カウントダウン
-   カウントダウン中は、タイマー時間を変更できない。
-   開始ボタンは押下できない。
-   アラーム画面へ切り替えた場合も、タイマーのカウントダウンを継続する。
-   ブラウザを終了した場合、カウントダウン中の状態は破棄する。
-   ブラウザを再度起動した場合は、初期状態で表示する。
-   残時間を1秒ごとに更新する。
-   残時間が「00:00:00」となった場合は、カウントダウンを終了する。

#### 2.2.4 一時停止
-   一時停止ボタン押下後は、一時停止ボタンを再開ボタンへ切り替える。
-   カウントダウン停止中は、再開ボタンおよびキャンセルボタンのみ押下可能とする。
-   アラーム画面へ切り替えた場合も、一時停止状態を維持する。
-   ブラウザを終了した場合、一時停止中の状態は破棄する。
-   ブラウザを再度起動した場合は、初期状態で表示する。
-   カウントダウン中は、一時停止操作を受け付ける。
-   一時停止操作を行った場合、残時間を保持したままカウントダウンを停止する。
-   再開操作を行った場合、停止時点の残時間からカウントダウンを再開する。
-   カウントダウン中および一時停止中は、キャンセル操作を受け付ける。

#### 2.2.5 再開
-   再開ボタン押下後に一時停止ボタンへ切り替わる。
-   カウントダウン再開後は、一時停止ボタンおよびキャンセルボタンのみ押下可能とする。
-   一時停止時点の残時間からカウントダウンを再開する。
-   アラーム画面へ切り替えた場合も、カウントダウンを継続する。

#### 2.2.6 キャンセル
-   キャンセル確認画面表示中はカウントダウンが一時停止状態となる。
-   キャンセル確認画面表示中は、「はい」「いいえ」のみ押下可能とする。
-   ・「はい」押下後に初期画面（00:00:00）へ戻り事前に設定したタイマー時刻は破棄される（履歴にも反映されない）

#### 2.2.7 タイマー終了
-   アラート終了ボタン表示中は、アラート終了ボタン以外の操作を受け付けない。（アラームの切り替えも不可）
-   タイマーの残時間が00:00:00となった場合、通知音を再生する。
-   通知音の再生時間は10秒とする。
-   アラート終了ボタンを押下した場合は、通知音の再生を停止する。
-   アラート終了ボタン表示中にブラウザ画面を閉じた場合は、アラート終了ボタンを押下できていない状態として、時刻設定前の初期画面（00:00:00）へ戻る。

#### 2.2.8 タイマー履歴
-   履歴はボタンとして表示する。
-   履歴は最大5件保持する。
-   新しい履歴を先頭へ追加する。
-   既存の履歴は1件ずつ下へ移動する。
-   5件を超えた場合は最も古い履歴を削除する。
-   アラート終了ボタンを押下した場合のみ保存する。
-   履歴の重複は許可する。
-   履歴ボタンを押下した場合、その時間をタイマー設定時間へ反映する。
-   履歴ボタン押下後はタイマー開始待ち状態とする。

#### 2.2.9 履歴再利用
-   履歴に表示した時刻は、再利用するためのボタンとして機能する。
-   同時に選択できる履歴ボタンは1件のみとする。
-   選択中の履歴ボタンは1件のみ保持する。
-   他の履歴ボタンを押下した場合は、前回選択した履歴ボタンの選択を解除し、新しく押下した履歴ボタンを選択状態とする。
-   選択した履歴ボタンの時間をタイマー設定時間へ反映する。
-   選択中の履歴ボタンを再度押下した場合は、選択状態を解除する。
-   選択状態を解除した場合は、タイマー設定時間を初期状態（00:00:00）へ戻す。
-   タイマー設定時間が00:00:00以外の場合は、開始ボタンを有効状態とする。

### 2.3 アラーム機能

#### 2.3.1 アラーム登録
-   アラームを登録できる。
-   アラームは**最大5件まで登録**できる。
-   登録件数が5件に達している場合は、新たなアラームを登録できない。

#### 2.3.2 時刻設定
-   アラーム設定時刻の**初期値は「00:00」の未設定状態**とする。
-   入力可能な範囲は、**時間（0～23）、分（0～59）**とする。
-   設定した時刻をアラーム設定時刻として保持する。
-   **「00:00」は有効な時刻**として設定可能とする。

#### 2.3.3 保存
-   設定したアラームを保存する。
-   **初期値「00:00」の状態でも保存できる**。
-   保存したアラームは通知後も保持する。
-   保存したアラームの有効状態の初期値はONとする。

#### 2.3.4 ON/OFF切替
-   保存したアラームの有効状態を切り替えられる。
-   ON状態のアラームは設定時刻に通知する。
-   OFF状態のアラームは設定時刻に通知しない。
-   ラジオボタンの選択状態は通知の有効／無効に影響しない。

#### 2.3.5  設定時間経過時の通知
-   **ON状態のアラーム**は、設定時刻に到達した場合にアラートを通知する。
-   OFF状態のアラームは、設定時刻に到達しても通知しない。
-   アラーム時刻は、**日本標準時刻**基準として判定する。

#### 2.3.6 アラート終了
-   アラート終了後も、アラームの有効状態は変更しない。

#### 2.3.7 スヌーズ機能
-   アラーム通知中にスヌーズ操作を受け付ける。
-   スヌーズ操作を行った場合、設定したスヌーズ間隔後に再度通知する。
-   スヌーズ中は元のアラーム設定を保持する。
-   アラート終了操作を行った場合はスヌーズを停止する。

#### 2.3.8 アラームの削除
-   削除対象のアラームを選択できる。
-   ラジオボタンは同時に1件のみ選択できる。
-   削除操作を行った場合、ラジオボタンで選択したアラームを削除する。
-   削除したアラームはLocalStorageから削除する。

## 3. エラー処理
-   音声の再生に失敗した場合は、エラー内容をコンソールへ出力する。

## 4. データ保存
-   アラーム設定はLocalStorageへ保存する。
-   削除時はLocalStorageから削除する。
-   タイマー履歴はLocalStorageへ保存する。
-   履歴削除時はLocalStorageから削除する。

# タイマーアプリ 画面仕様（別シート参照）
## 1. 概要

本書ではタイマーアプリの画面仕様を定義する。画面デザインの詳細については別シートを参照する。

## 2. レイアウト

### 2.1 共通
-   タイマー／アラーム切り替えボタンを配置する。

### 2.2 タイマー画面
-   タイマー時間設定スクロールバーを配置する。
-   タイマー開始ボタンを配置する。
-   タイマー残時間表示エリアを配置する。
-   タイマー一時停止／再開ボタンを配置する。
-   タイマーキャンセルボタンを配置する。
-   タイマー履歴表示エリア（最大5件）を配置する。
-   タイマー履歴ボタン（最大5件）を配置する。

### 2.3 アラーム画面
-   アラーム時刻設定スクロールバーを配置する。
-   アラーム追加ボタンを配置する。
-   アラーム保存ボタンを配置する。
-   保存済みアラームごとにラジオボタンを配置する。
-   アラーム設定履歴表示エリア（最大5件）を配置する。
-   アラーム有効／無効切り替えボタン（ON／OFF）を配置する。
-   アラーム削除ボタンを配置する。

### 2.4 アラート画面
-   タイマー終了またはアラーム通知のメッセージを表示する。
- 　アラート終了ボタンを配置する。

## 3. デザイン

### 3.1 デザイン
-   タイマーおよびアラームの時刻設定は、スクロールバーによる入力のみ可能とする。
-   タイマーおよびアラームの設定値は、各項目を**2桁で表示**する(例：01:30:45、00:05)。
-   表示エリアには設定時間または残時間を表示する。
-   ボタンの配置およびサイズはデザイン資料に従う。
-   ボタンのラベルは日本語で表示する。
-   ボタンの表示文は本書で定義した名称を使用する。
-   **アラーム有効／無効切り替えボタンは「ON」「OFF」で表示**とする。
-   無効状態のボタンは灰色で表示し、押下できない状態とする。
-   アラート画面には終了ボタンを配置する。

## 4. 画面仕様

### 4.1 タイマー画面

#### 4.1.1 時間設定スクロールバー入力
-   タイマー残時間表示エリアを配置する。
-   時間・分・秒スクロールバーを配置する。
-   アラーム切替ボタンを配置する。
-   押下できないボタンは灰色表示とする。
-   タイマー設定時間が未設定状態と設定済み状態で視覚的に区別できること。

#### 4.1.2 タイマー開始ボタン
-   開始ボタンを配置する。
-   開始ボタンは有効状態および無効状態を表示できること。
-   無効状態では灰色で表示する。

#### 4.1.3 タイマー残時間表示
-   タイマーの残時間を表示エリアへ表示する。

#### 4.1.4 タイマー一時停止/再開切り替えボタン
-   一時停止／再開ボタンを配置する。
-   カウントダウン中は「一時停止」を表示する。
-   一時停止中は「再開」を表示する。
-   利用できない状態では灰色表示とする。

#### 4.1.5 タイマー途中キャンセルボタン
-   キャンセルボタンを配置する。
-   キャンセル確認画面を表示する。
-   キャンセル確認画面に「はい」「いいえ」ボタンを配置する。
-   カウントダウン中および一時停止中に表示する。

#### 4.1.6 タイマーアラート終了ボタン
-   アラート終了ボタンを配置する。
-   アラート画面に表示する。
-   アラート表示中のみ操作可能とする。

#### 4.1.7 タイマー履歴表示
-   保存済みのタイマー時間を一覧表示する。
-   タイマー履歴ボタンを最大5件表示する。
-   履歴が存在しない場合は一覧を表示しない。

#### 4.1.8 履歴再利用
-   選択中の履歴ボタンは青色で表示する。
-   未選択の履歴ボタンは通常色で表示する。
-   同時に選択状態となる履歴ボタンは1件のみとする。

### 4.2 アラーム画面

#### 4.2.1 アラーム追加ボタン
-   アラーム追加ボタンを配置する。
-   登録件数が5件の場合、追加ボタンを無効表示とする。

#### 4.2.2 アラーム数字スクロールバー入力
-   アラーム時刻設定用スクロールバーを配置する。
-   初期表示は「00:00」とする。
-   時間（0〜23）、分（0〜59）をスクロールバーで選択できる。
-   設定した時刻を表示エリアに反映する。

#### 4.2.3 アラーム保存ボタン
-   アラーム保存ボタンを配置する。

#### 4.2.4 アラーム設定履歴表示画面
-   保存済みアラームの一覧を表示するエリアを配置する。
-   アラームは最大5件まで表示する。
-   保存済みアラームごとにラジオボタンを表示する。
-   ラジオボタンは同時に1件のみ選択できる。
-   ラジオボタンの選択状態はアラームの通知に影響しない。

#### 4.2.5 アラーム有効／無効切り替えボタン
-   アラームの有効／無効を切り替えるボタンを配置する。
-   ボタン表示はON／OFFで切り替わる。
-   有効状態はON、無効状態はOFFとして表示する。

#### 4.2.6 アラームアラート終了ボタン
-   アラート終了ボタンを配置する。
-   アラート画面に表示する。

#### 4.2.7 アラーム設定済項目の削除ボタン
-   アラーム削除ボタンを配置する。
-   アラーム設定履歴の各項目に表示する。

### 4.3 アラート画面
-   アラートメッセージを表示する。
-   アラート終了ボタンを配置する。
-   スヌーズボタンを配置する。
-   アラート表示中のみ操作可能とする。
