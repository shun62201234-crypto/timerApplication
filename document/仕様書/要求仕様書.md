# タイマー・アラームアプリ 要求仕様
## 1. 概要
本アプリケーションは、ブラウザ上で動作するタイマー・アラームアプリケーションである。
設定した時間をカウントダウンするタイマー機能と、指定した時刻に通知を行うアラーム機能を実行できる。
**ユーザーはタイマー機能とアラーム機能を切り替えて** 利用できる。
タイマー機能とアラーム機能は独立して動作し、同時に通知が発生した場合も、それぞれの通知を個別に管理する。
画面上の表示、入力方法、ボタン状態、選択状態等の詳細については、別途「画面仕様」を参照する。

## 2. 対象環境
### 2.1  開発環境
-   使用言語: TypeScript
-   使用ツール: Vite, VSCode

### 2.2 動作環境
-   Google Chrome 最新版
-   Microsoft Edge 最新版

## 3. 機能要求
### 3.1 共通
-   タイマーモードとアラームモードを切り替えて利用できること。
-   タイマー状態とアラーム状態を独立して管理できること。
-   モード切替時も各モードの状態を保持すること。
-   タイマー終了時またはアラーム時刻到達時はユーザーへ通知すること。
-   タイマー通知とアラーム通知が同時に発生した場合、それぞれの通知を個別に表示・管理できること。
-   一方の通知を操作しても、もう一方の通知に影響を与えないこと。
-   モード切替時も、発生済みの未操作通知を引き継ぐこと。
-   通知音を再・停止できること。

### 3.2 タイマー
-   タイマー時間を設定できること。
-   タイマー時間は、時間・分・秒を設定できること。
-   タイマーを開始、カウントダウン、一時停止、再開およびキャンセルできること。
-   タイマー終了時にユーザーへ通知できること。
-   タイマー履歴を保存できること。
-   保存したタイマー履歴を再利用できること。

### 3.3 アラーム
-   アラーム時刻を設定できること。
-   アラーム時刻は、時間・分を設定できること。
-   設定したアラームを保存できること。
-   保存したアラームをON/OFF切り替えできること。
-   ON状態のアラームは設定時刻に通知できること。
-   OFF状態のアラームは、設定時刻に通知しないこと。
-   アラーム通知中にスヌーズを利用できること。
-   保存したアラームを削除できること。
-   同一時刻のアラームを複数登録できること。
-   削除またはOFFにしない限り、翌日以降も設定時刻に通知すること。

## 4. 非機能要求
### 4.1 データ保存
-   アラーム設定およびタイマー履歴は、ブラウザ終了後も保持する。
-   アラーム設定およびタイマー履歴はLocalStorageに保存する。
-   LocalStorageから保存データを読み込めない場合は、該当データを初期状態として扱う。
-   LocalStorageへの保存に失敗した場合は、エラー内容をコンソールへ出力する。

### 4.2 時刻
-   アラームの時刻判定は**日本標準時（JST）**を基準とする。
-   アラームの時刻判定には現在時刻を使用する。
-   ブラウザまたは端末の停止・スリープ等により設定時刻を経過した場合、復帰後に過去の時刻に遡って通知しない。
-   アラーム設定時刻と現在時刻が一致する状態でアラームを保存した場合は、保存直後に通知する。

### 4.3 音声
-   タイマー終了時およびアラーム通知時に通知音を再生する。
-   通知音の再生時間は60秒とする。
-   通知終了操作により、対象通知の通知音を停止できる。
-   アプリケーション内で管理する音量が0の場合でも、音声再生処理自体は実行する。
-   音声の再生に失敗した場合は、エラー内容をコンソールへ出力する。
-   複数の通知が発生した場合、最初に発生した通知の通知音を優先する。後続の通知音は再生しない。
-   最初の通知音が再生中に後続の通知が発生した場合も、後続の通知音は再生しない。
-   最初の通知音が最大60秒の再生を終えた後も、後続の通知音を再生しない。
-   通知音を再生しない通知についても、通知状態および通知表示は通常どおり維持する。

## 5. 共通機能仕様
### 5.1 モード切替
-   タイマー状態とアラーム状態は独立して管理する。
-   タイマー動作中にアラーム画面へ切り替えた場合、タイマーの動作状態を保持する。
-   タイマーが一時停止中にアラーム画面へ切り替えた場合、一時停止状態を保持する。
-   アラームモードからタイマーモードへ切り替えた場合、タイマーの状態を保持する。
-   保存済みアラーム設定は、モードを切り替えても保持する。
-   モード切替によって、タイマーの開始・一時停止・再開・キャンセルや、アラームのON/OFF状態を変更しない。

#### 5.2 通知の基本管理
-   アラーム通知とタイマー終了通知は独立して管理する。
-   各通知は、通知状態、表示状態、終了状態および必要なスヌーズ状態を個別に管理する。
-   タイマー終了時またはアラーム時刻到達時にそれぞれの通知状態へ遷移する。
-   同時に複数の通知が発生した場合、それぞれの通知を個別に表示・管理する。
-   一方の通知に対する終了またはスヌーズ操作は、操作対象の通知だけに適用する。
-   一方の通知を操作しても、他の通知の状態、処理および表示順序に影響を与えない。
-   通知テロップは、対応する操作が行われるまで表示し続ける。
-   通知音の再生が終了した場合でも、通知終了操作が行われるまで通知状態を維持する。
-   アラート音は最大60秒間再生する。
-   通知終了操作は、対象通知が通知中またはスヌーズ中の場合に受け付ける。
-   通知終了操作により、対象通知を終了する。

### 5.3 通知の振り分けルール
-   通知の表示位置は、現在選択されているモードと通知の種類に応じて決定する。
-   タイマーモードでは、タイマー終了通知を中央表示の対象とし、アラーム通知は左下表示の対象とする。
-   アラームモードでは、最初に発生したアラーム通知を中央表示の対象とし、それ以外のアラーム通知およびタイマー終了通知は左下表示の対象とする。
-   同一時刻に複数のON状態アラームが発生した場合は、すべてのアラームを通知対象とする。
-   同一時刻に複数のアラームが発生した場合、設定一覧で最も上にあるアラームを最初のアラームとして扱い、中央表示の対象とする。
-   同時刻に発生したその他のアラームは、左下表示の対象とする。
-   中央表示中の通知が終了またはスヌーズされた場合、既に発生している別の通知を中央表示へ移動させない。
-   中央表示の通知がなくなった場合、中央表示は空の状態とする。
-   左下表示中の通知は、他の通知の終了またはスヌーズによって表示位置を変更しない。

### 5.4 通知の表示順序
-   左下表示の通知は、発生した順に並べる。
-   新しい通知は、既存の通知の一番下に追加する。
-   同時刻に複数のアラームが発生した場合は、設定一覧の上から順に扱う。
-   通知の終了またはスヌーズによって、残っている通知の順序を変更しない。
-   スヌーズによる再通知は、スヌーズ操作時点の表示位置を維持する。
-   スヌーズによる再通知先に同じ表示位置の通知が既に存在する場合、既存通知の順序を変更せず、再通知をその位置の一番下に追加する。

### 5.5 モード切替時の通知状態・表示位置
-   モードを切り替えても、発生済み通知の状態を維持する。
-   通常の未操作通知の表示位置は、切替後のモードに応じて振り分け直す。
-   モード切替前に中央表示されていた通常の未操作通知は、切替後に左下表示へ移す。
-   モード切替によって、通知の終了・解除・スヌーズ状態の変更を行わない。
-   モード切替によって、通知音の再生状態を解除または変更しない。
-   スヌーズ中の通知は、モードを切り替えてもスヌーズ操作時点の表示位置を維持する。
-   スヌーズ中の通知が再通知される場合も、スヌーズ操作時点の表示位置を維持する。
-   モード切替によって、未操作通知を消去しない。

### 5.6 ブラウザ終了・再起動
-   ブラウザ起動中のみ、タイマーおよびアラーム機能を動作させる。
-   ブラウザ終了時、動作中のタイマー状態を破棄する。
-   ブラウザ終了時、タイマーの一時停止状態を破棄する。
-   ブラウザ終了時、発生済みの通知状態を破棄する。
-   ブラウザ終了時、アラームのスヌーズ状態および予約済みの再通知を破棄する。
-   ブラウザ終了時、設定中で保存されていないアラーム時刻を破棄する。
-   ブラウザ再起動時は、保存済みのアラーム設定およびタイマー履歴を復元する。
-   ブラウザ再起動時、タイマーは初期状態とする。
-   ブラウザ再起動時、通知中またはスヌーズ中の状態は復元しない。

## 6. タイマー機能仕様
### 6.1 時間設定
-   タイマー設定時間の**初期値は「00:00:00」**とする。
-   入力可能な範囲は、**時間(0～23)、分(0～59)、秒(0～59)**とする。
-   設定した時間をタイマー設定値として保持する。
-   00:00:00の場合、**開始操作を受け付けない**。
-   00:00:00以外の場合、タイマーを開始できる。

### 6.2 開始
-   タイマー開始後、設定時間からカウントダウンを開始する。
-   タイマー開始時に、設定時間をタイマー処理内で保持する。
-   タイマー開始後は、設定時間を変更できない。
-   タイマー開始時に、設定時間をタイマー履歴として保存する。
-   アラーム画面へ切り替えた場合も、タイマーのカウントダウンを継続する。

### 6.3 カウントダウン
-   タイマーの残時間は、現在時刻と終了予定時刻との差分から算出する。
    -   終了予定時刻 = 開始時刻 + 設定時間
    -   残時間 = 終了予定時刻 - 現在時刻
-   残時間が00:00:00となった場合、カウントダウンを終了する。

### 6.4 一時停止・再開
-   カウントダウン中は、一時停止操作を受け付ける。
-   一時停止操作を行った場合、一時停止時点の残時間を秒単位で保持する。
-   一時停止中はカウントダウンを停止する。
-   再開操作を行った場合、保持している残時間からカウントダウンを再開する。
-   再開後は、再度一時停止操作を受け付ける。
-   カウントダウン中および一時停止中は、キャンセル操作を受け付ける。

### 6.5 キャンセル
-   カウントダウン中または一時停止中にタイマーをキャンセルできる。
-   キャンセル操作時は、キャンセル確認を行う。
-   キャンセル確認中は、タイマーのカウントダウンを一時停止する。
-   「はい」を選択した場合、タイマーをキャンセルする。
-   キャンセルしたタイマーの設定時間および残時間を破棄する。
-   キャンセルしたタイマーの履歴は削除せず、保持する。
-   「いいえ」を選択した場合、キャンセル確認前の状態へ戻る。
-   キャンセル確認前がカウントダウン中の場合は、カウントダウンを再開する。
-   キャンセル確認前が一時停止中の場合は、一時停止状態へ戻る。

### 6.6 終了通知
-   タイマーの残時間が00:00:00となった場合、タイマーを終了する。
-   タイマー終了時に通知状態へ遷移する。
-   タイマー終了時に通知音を再生する。
-   通知終了操作を行うまで、タイマー終了通知状態を維持する。
-   通知終了操作を行うまで、タイマー終了通知を表示状態として維持する。
-   アラーム通知中にタイマーが終了した場合も、タイマーを終了し、タイマー終了通知を発生させる。
-   タイマー終了通知は、アラーム通知とは独立して管理する。
-   タイマー終了通知の「終了」操作のみ受け付ける。
-   タイマー終了通知の操作は、アラーム通知の状態に影響を与えない。

### 6.7 履歴保存
-   タイマー開始時に、設定時間をタイマー履歴として保存する。
-   保存する履歴は、タイマー終了時の設定時間とする。
-   タイマー開始時に保存した履歴は、タイマー終了後も保持する。
-   タイマーをキャンセルした場合も、開始時に保存した履歴を削除せず保持する。
-   タイマー履歴は最大5件保持する。
-   6件目の履歴を保存する場合、最も古い履歴を削除する。
-   新しい履歴を一覧の先頭に追加する。
-   同一時間の履歴を複数保存できる。

### 6.8 履歴再利用
-   保存したタイマー履歴を選択して再利用できる。
-   履歴を選択した場合、履歴に保存されている時間をタイマー設定時間へ反映する。
-   履歴を再利用した場合、タイマーは開始待ち状態とする。
-   選択できる履歴は1件のみとする。
-   別の履歴を選択した場合、以前の選択を解除し、新しく選択した履歴を選択状態とする。
-   履歴の選択を解除した場合、タイマー設定時間を00:00:00へ戻す。
-   タイマー設定時間が00:00:00以外の場合、タイマーを開始できる。

## 7. アラーム機能仕様
### 7.1 アラーム登録
-   アラームを登録できる。
-   アラームは**最大5件まで登録**できる。
-   登録件数が5件の場合、新たなアラームを登録できない。
-   同一時刻のアラームを複数登録できる。

### 7.2 時刻設定
-   アラーム設定時刻の**初期値は「00:00」**とする。
-   入力可能な範囲は、**時間(0～23)、分(0～59)**とする。
-   00:00は有効なアラーム設定時刻として扱う。
-   設定中のアラームは、保存するまで登録済みアラームとして扱わない。

### 7.3 保存
-   設定したアラームを保存できる。
-   00:00の状態でも保存できる。
-   保存直後のアラーム状態はONとする。
-   保存したアラームは、通知後も保持する。
-   保存したアラームは、削除またはOFFにしない限り、翌日以降も同じ時刻に通知する。
-   保存したアラーム時刻と現在時刻が一致する場合は、保存直後に通知する。

### 7.4 ON/OFF
-   保存したアラームはON/OFFを切り替えできる。
-   ON状態のアラームは、設定時刻に通知する。
-   OFF状態のアラームは、設定時刻に到達しても通知しない。
-   ON/OFF状態の変更は保存する。
-   アラームを削除していない限り、ON/OFF状態を保持する。

### 7.5 通知
-   ON状態のアラームが設定時刻に到達した場合、通知状態へ遷移する。
-   アラーム通知開始時に、通知音の再生対象となる。
-   アラーム音の再生終了後も、通知終了操作が行われるまで通知状態を維持する。
-   アラーム終了後も、アラーム設定およびON/OFF状態を保持する。
-   アラームは翌日以降も設定時刻に通知する。
-   アラーム時刻の判定はJSTを基準とする。
-   過去の時刻に遡って通知しない。
-   同一時刻に複数のON状態アラームが通知対象となった場合、該当するすべてのアラームを通知対象とする。
-   同時刻に発生した各アラーム通知は、それぞれ独立して管理する。
-   各アラーム通知は個別に終了またはスヌーズできる。
-   1件のアラーム通知に対する操作は、その他のアラーム通知の状態および処理に影響を与えない。
-   タイマー動作中にアラーム時刻へ到達した場合も、アラーム通知を行う。
-   タイマー終了通知中にアラーム時刻へ到達した場合も、アラーム通知を行う。
-   アラーム通知は、タイマー終了通知とは独立して管理する。
-   アラーム通知の操作は「終了」または「スヌーズ」とする。

### 7.6 スヌーズ
-   アラーム通知中にスヌーズ操作を行える。
-   スヌーズ操作を行った場合、アラーム通知を一時停止し、5分間のスヌーズ状態とする。
-   スヌーズ時間は5分とする。
-   スヌーズ時間経過後、再度アラーム通知を再度通知する。
-   スヌーズは複数回利用できる。
-   スヌーズ回数に上限を設けない。
-   スヌーズ操作を行うたびに、5分後に再度通知する。
-   スヌーズ中は、対象通知に対する「終了」操作を受け付ける。
-   スヌーズ中に「終了」操作を行った場合、対象通知を完全に終了し、予約済みのスヌーズ再通知も取り消す。
-   スヌーズ中にブラウザを終了した場合、スヌーズ状態および予約済みの再通知を破棄する。
-   スヌーズした通知は、スヌーズ操作を行った時点の表示位置を維持して再通知する。
-   スヌーズした通知は、スヌーズ操作を行った時点の表示位置を維持して再通知する。
-   スヌーズ中にモードを切り替えた場合も、スヌーズ操作時の表示位置を維持する。
-   スヌーズした通知の再通知によって、他の通知の表示位置や表示順序を変更しない。
-   再通知先に同じ表示位置の通知が既に存在する場合、既存通知の順序を変更せず、再通知をその位置の一番下に追加する。

### 7.7 通知競合
-   タイマー通知とアラーム通知は、それぞれ独立して管理する。
-   タイマー通知とアラーム通知が同時に発生した場合、それぞれの通知を個別に表示する。
-   アラーム通知中にタイマーが終了した場合、タイマーのカウントダウンは終了し、、タイマー終了通知を発生させる。
-   タイマー動作中にアラーム時刻へ到達した場合、タイマーのカウントダウンを継続し、アラーム通知を発生させる。
-   一方の通知に対して操作を行っても、もう一方の通知は表示、通知状態および処理状態に影響を与えない。
-   モード切替時も、発生済みの未操作通知を引き継ぐ。
-   通知の表示位置および表示順序は、5.3～5.5の共通機能仕様に従う。
-   通知音の優先順位は、4.3の音声仕様に従う。

### 7.8 通知終了
-   アラーム通知中に終了操作を行った場合、アラーム通知を終了する。
-   終了操作により、対象通知の音声を停止する。
-   終了後もアラーム設定およびON/OFF状態は保持する。
-   通知終了後も、アラームがON状態であれば翌日以降の通知を継続する。
-   スヌーズ中に終了操作を行った場合、対象の通知および予約済みのスヌーズ再通知を取り消す。
-   アラーム通知に対する操作は、タイマー終了通知の表示および状態に影響を与えない。
-   タイマー終了通知中に「終了」操作を行った場合、タイマー終了通知を終了する。
-   タイマー終了通知の終了操作により、タイマー終了通知音を停止する。
-   タイマー終了通知に対する操作は、アラーム通知の表示および状態に影響を与えない。

### 7.9 削除
-   保存済みアラームを削除できる。
-   削除対象のアラームを1件または複数件選択して削除できる。
-   ON/OFF状態にかかわらず、アラームを削除できる。
-   削除したアラームは登録対象から除外する。
-   通知中またはスヌーズ中のアラームを削除した場合、対象アラームに紐づく通知を終了する。
-   通知中またはスヌーズ中のアラームを削除した場合、対象アラームに紐づく予約済みのスヌーズ再通知も取り消す。
-   アラームの削除は、他のアラーム通知およびタイマー終了通知に影響を与えない。

## 8. データ保存
### 8.1 保存対象
LocalStorageに以下のデータを保存する。
-   アラーム設定
   -   アラームを識別するID
   -   アラーム時刻
   -   ON/OFF状態
-   タイマー履歴
   -   履歴ID
   -   タイマー設定時間

### 8.2 保存タイミング
-   アラームを保存した時点で、アラーム設定をLocalStorageへ保存する。
-   アラームのON/OFF状態を変更した時点で、LocalStorageを更新する。
-   アラームを削除した時点で、LocalStorageから対象アラームを削除する。
-   タイマー開始時に、設定時間をタイマー履歴としてLocalStorageへ保存する。
-   タイマーをキャンセルした場合も、保存済みタイマー履歴をLocalStorageに保持する。

### 8.3 復元
-   アプリケーション起動時にLocalStorageから保存済みアラーム設定を読み込む。
-   アプリケーション起動時にLocalStorageから保存済みタイマー履歴を読み込む。
-   保存データの読み込みに失敗した場合は、該当データを初期状態として扱う。
-   ブラウザ再起動時に復元するデータは、保存済みアラーム設定およびタイマー履歴とする。
-   動作中タイマー、通知中の状態およびスヌーズ中の状態は復元しない。

## 9. エラー処理
-   音声の再生に失敗した場合は、エラー内容をコンソールへ出力する。
-   LocalStorageに保存されたデータの読み込みに失敗した場合は、該当データを初期状態として扱う。
-   LocalStorageへの保存に失敗した場合は、エラー内容をコンソールへ出力する。

## 10. 制約事項
| 項目 | 内容 |
| ---- | ---- |
| 入力方法 | ボタン操作およびスクロール操作のみに限定する |
| 表示言語 | 日本語のみとする |
| タイマー最大時間 | 23:59:59 |
| アラーム最大登録数 | 5件 |
| タイマー履歴最大保持数 | 5件 |
| アラーム重複登録 | 同一時刻のアラームを複数登録可能とする |
| タイマー履歴重複 | 同一時間の履歴を複数保存可能とする |
| スヌーズ時間 | 5分  |
| スヌーズ回数 | 上限なし |
| 通知音再生時間 | 最大60秒 |
| 通知音の優先 | 最初に発生した通知音のみ再生し、後続の通知音は再生しない |
| 時刻基準 | 日本標準時（JST） |
| Undo機能 | 直前に行った操作や処理を取り消し、元の状態に戻すアンドゥー機能は考慮しない |
