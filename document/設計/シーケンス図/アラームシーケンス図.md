# アラームシーケンス図
## 1. アラーム登録 成功パターン
```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Clock as 時刻管理
    participant Alarm as アラーム処理
    participant Storage as LocalStorage
    participant Notify as 通知管理処理
    participant UI as アラーム画面
    participant Audio as 音声処理

    User->>+UI: アラーム追加を選択
    UI->>+Alarm: アラーム追加要求
    Alarm->>Storage: 登録済み件数を取得
    Storage-->>Alarm: 登録済み件数を返却

    alt 登録済み件数が5件未満
        Alarm-->>-UI: 追加設定を開始
        UI-->>-User: 初期時刻00:00を表示

        User->>+UI: 時刻を設定して保存
        UI->>+Alarm: アラーム保存要求
        Alarm->>Alarm: アラーム情報を作成（ON状態）
        Alarm->>Storage: アラーム情報を保存
        Storage-->>Alarm: 保存成功
        Alarm->>Clock: 現在時刻を取得
        Clock-->>Alarm: 現在時刻を返却

        alt 設定時刻と現在時刻が一致
            Alarm->>+Notify: 対象アラームの通知を開始
            Notify-->>-Alarm: 通知登録完了
        else 設定時刻と現在時刻が不一致
            Alarm->>Alarm: 通知対象時刻まで待機
        end

        Alarm-->>-UI: 保存結果を返却
        UI->>UI: 設定画面をリセット
        UI-->>-User: 保存後の画面を表示

    else 登録済み件数が5件
        Alarm-->>+UI: 追加不可を通知
        UI-->>+User: アラーム追加不可を表示
    end
```

## 2. アラーム登録 失敗パターン
```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Clock as 時刻管理
    participant Alarm as アラーム処理
    participant Storage as LocalStorage
    participant Notify as 通知管理処理
    participant UI as アラーム画面
    participant Audio as 音声処理

    User->>+UI: 時刻を設定して保存
    UI->>+Alarm: アラーム保存要求
    Alarm->>Alarm: アラーム情報を作成（ON状態）
    Alarm->>Storage: アラーム情報を保存

    alt LocalStorageへの保存に失敗
        Storage-->>Alarm: 保存失敗とエラー情報
        Alarm->>Alarm: エラー内容を記録
        Note over Alarm,UI: 保存失敗時の画面状態や入力値の扱いは未定義
        Alarm-->>UI: 保存失敗を返却
    else LocalStorageへの保存に成功
        Storage-->>Alarm: 保存成功
        Alarm-->>UI: 保存成功を返却
    end

    Alarm-->>-UI: 保存処理完了
    UI-->>-User: 保存結果を通知
```

## 3. アラーム通知
```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Clock as 時刻管理
    participant Alarm as アラーム処理
    participant Storage as LocalStorage
    participant Notify as 通知管理処理
    participant UI as アラーム画面
    participant Audio as 音声処理

    Clock->>+Alarm: 現在時刻を通知
    Alarm->>Storage: ON状態のアラーム情報を取得
    Storage-->>Alarm: アラーム一覧を返却
    Alarm->>Alarm: 現在時刻とアラーム時刻を照合

    alt 通知対象のアラームが存在する
        loop 通知対象のアラームごと（設定一覧の上から順）
            Alarm->>+Notify: アラームIDを指定して通知登録
            Notify->>Notify: 通知IDを付与して個別管理
            Notify->>UI: 通知表示を要求
            Note over Notify,UI: アラームモードでは最初のアラームを中央に表示し、その他は左下に発生順で表示する
            Notify-->>-Alarm: 通知登録完了
        end

        Alarm->>+Audio: 通知音の再生可否を確認
        alt まだ通知音が再生対象になっていない
            Audio->>Audio: 最初の通知音の再生を開始
            Note over Audio: 通知音は最大60秒。再生終了後も後続通知音は再生しない
        else すでに先行通知の音声が再生対象になっている
            Audio->>Audio: 新たな通知音は再生しない
        end
        Audio-->>-Alarm: 音声処理完了
    else 通知対象のアラームが存在しない
        Alarm->>Alarm: 通知処理を行わない
    end

    Alarm-->>-Clock: 時刻判定処理完了
```

## 4. アラーム通知～スヌーズ
```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Clock as 時刻管理
    participant Alarm as アラーム処理
    participant Storage as LocalStorage
    participant Notify as 通知管理処理
    participant UI as アラーム画面
    participant Audio as 音声処理

    Notify->>+UI: 対象アラームの通知を表示
    UI-->>-User: 通知と操作ボタンを表示

    User->>+UI: スヌーズを選択
    UI->>+Notify: 対象通知のスヌーズ要求
    Notify->>Notify: 対象通知をスヌーズ中に変更
    Notify->>Notify: 現在の表示位置を保持
    Notify->>Clock: 5分後の再通知を予約
    Clock-->>Notify: 再通知予約完了
    Notify-->>-UI: スヌーズ中表示を要求
    UI-->>-User: スヌーズ中メッセージ・残時間・終了ボタンを表示

    opt スヌーズ中のモード切替
        User->>+UI: モード切替
        UI->>+Notify: 表示モード変更を通知
        Notify->>UI: 表示モードに応じて画面を更新
        Note over Notify,UI: スヌーズ中の通知は表示位置を維持する
        Notify-->>-UI: 表示更新完了
        UI-->>-User: 切替後の画面を表示
    end

    opt スヌーズ中のアラーム削除
        User->>+UI: 対象アラームの削除
        UI->>+Alarm: アラーム削除要求
        Alarm->>Storage: 対象アラームを削除
        Storage-->>Alarm: 削除結果を返却
        Alarm->>+Notify: 対象通知と再通知予約の取消
        Notify->>Clock: 対象の再通知予約を取消
        Clock-->>Notify: 予約取消完了
        Notify->>Notify: 対象通知のみ終了
        Notify-->>-Alarm: 通知取消完了
        Alarm-->>-UI: 削除結果を返却
        UI-->>-User: 削除結果を反映
    end

    alt 5分経過前に終了を選択
        User->>+UI: 終了を選択
        UI->>+Notify: 対象通知の終了要求
        Notify->>Clock: 対象の再通知予約を取消
        Clock-->>Notify: 予約取消完了
        Notify->>Notify: 対象通知のみ終了
        Notify-->>-UI: 通知終了結果を返却
        UI-->>-User: 対象通知を非表示
    else 5分経過
        Clock->>+Notify: 再通知時刻到達
        Notify->>Notify: 対象通知を通知中に変更
        Notify->>+UI: 保持していた表示位置で再通知
        UI-->>-Notify: 表示更新完了
        Notify->>+Audio: 通知音の再生可否を確認
        alt まだ通知音が再生対象になっていない
            Audio->>Audio: 通知音の再生を開始
        else すでに先行通知の音声が再生対象になっている
            Audio->>Audio: 通知音を再生しない
        end
        Audio-->>-Notify: 音声処理完了
        Notify-->>-Clock: 再通知処理完了

        Note over Notify,UI: 再通知後は終了・スヌーズ操作を受け付ける。再度スヌーズした場合は、その時点の表示位置を保持して5分後に再通知する
    end

    opt ブラウザ終了
        User->>+UI: ブラウザを終了
        UI->>+Notify: 通知状態の破棄
        Notify->>Notify: スヌーズ状態と再通知予約を破棄
        Notify-->>-UI: 破棄完了
        UI-->>-User: ブラウザ終了
    end
```

## 5. アラーム通知中にタイマーが終了した場合
```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Clock as 時刻管理
    participant Alarm as アラーム処理
    participant Storage as LocalStorage
    participant Notify as 通知管理処理
    participant UI as アラーム画面
    participant Audio as 音声処理

    Alarm->>+Notify: アラーム通知を登録
    Notify->>Notify: アラーム通知を個別管理
    Notify->>+UI: アラーム通知の表示を要求
    UI-->>-Notify: アラーム通知表示完了

    Notify->>+Audio: アラーム通知音の再生要求
    Audio->>Audio: アラーム通知音の再生を開始
    Audio-->>-Notify: 音声再生開始

    Clock->>Notify: タイマー終了を通知
    Notify->>Notify: タイマー終了通知を個別管理
    Notify->>+UI: タイマー終了通知の表示を要求
    Note over Notify,UI: 通知位置は現在のモードに従う。アラーム通知とタイマー終了通知は独立して表示する
    UI-->>-Notify: タイマー終了通知表示完了

    Notify->>+Audio: タイマー終了通知音の再生要求
    Audio->>Audio: 先行するアラーム通知音が再生対象のため再生しない
    Audio-->>-Notify: 音声処理完了

    Note over Notify,UI: アラーム通知とタイマー終了通知はそれぞれ終了操作まで表示を維持する

    opt アラーム通知の終了操作
        UI->>+Notify: アラーム通知の終了要求
        Notify->>Notify: 対象アラーム通知のみ終了
        Notify->>+UI: アラーム通知の非表示を要求
        UI-->>-Notify: 表示更新完了
        Notify-->>-UI: 通知終了結果を返却
    end

    opt タイマー終了通知の終了操作
        UI->>+Notify: タイマー終了通知の終了要求
        Notify->>Notify: タイマー終了通知のみ終了
        Notify->>+UI: タイマー終了通知の非表示を要求
        UI-->>-Notify: 表示更新完了
        Notify-->>-UI: 通知終了結果を返却
    end
```

## 6. タイマー通知中にアラーム時刻へ到達した場合
```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Clock as 時刻管理
    participant Alarm as アラーム処理
    participant Storage as LocalStorage
    participant Notify as 通知管理処理
    participant UI as アラーム画面
    participant Audio as 音声処理

    Clock->>+Notify: タイマー終了を通知
    Notify->>Notify: タイマー終了通知を個別管理
    Notify->>+UI: タイマー終了通知の表示を要求
    UI-->>-Notify: タイマー終了通知表示完了

    Notify->>+Audio: タイマー終了通知音の再生要求
    Audio->>Audio: タイマー終了通知音の再生を開始
    Audio-->>-Notify: 音声再生開始

    Clock->>+Alarm: 現在時刻を通知
    Alarm->>Storage: ON状態のアラーム情報を取得
    Storage-->>Alarm: アラーム一覧を返却
    Alarm->>Alarm: 現在時刻とアラーム時刻を照合

    alt 通知対象のアラームが存在する
        loop 通知対象のアラームごと（設定一覧の上から順）
            Alarm->>Notify: アラームIDを指定して通知登録
            Notify->>Notify: アラーム通知を個別管理
            Notify->>+UI: アラーム通知の表示を要求
            Note over Notify,UI: タイマーモードではタイマー終了通知を中央、アラーム通知を左下に表示する
            UI-->>-Notify: アラーム通知表示完了
            Notify-->>Alarm: 通知登録完了
        end

        Alarm->>+Audio: アラーム通知音の再生要求
        Audio->>Audio: 先行するタイマー終了通知音が再生対象のため再生しない
        Audio-->>-Alarm: 音声処理完了
    else 通知対象のアラームが存在しない
        Alarm->>Alarm: アラーム通知を行わない
    end

    Alarm-->>-Clock: アラーム時刻判定完了

    Note over Notify,UI: タイマー終了通知とアラーム通知は独立して維持し、それぞれの終了操作まで表示する

    opt タイマー終了通知の終了操作
        UI->>+Notify: タイマー終了通知の終了要求
        Notify->>Notify: タイマー終了通知のみ終了
        Notify->>+UI: タイマー終了通知の非表示を要求
        UI-->>-Notify: 表示更新完了
        Notify-->>-UI: 通知終了結果を返却
    end

    opt アラーム通知の終了操作
        UI->>+Notify: アラーム通知の終了要求
        Notify->>Notify: 対象アラーム通知のみ終了
        Notify->>+UI: アラーム通知の非表示を要求
        UI-->>-Notify: 表示更新完了
        Notify-->>-UI: 通知終了結果を返却
    end
```
