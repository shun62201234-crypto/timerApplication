# タイマーシーケンス図
## 1. タイマー開始～終了（通常ケース）
```mermaid
sequenceDiagram
    actor ユーザー
    participant UI as タイマー画面
    participant Timer as タイマー処理
    participant Storage as LocalStorage
    participant Notify as 通知管理処理
    participant Audio as 音声処理

    ユーザー->>UI: 時間を設定
    UI->>+Timer: タイマー設定時間を設定
    Timer-->>-UI: 設定完了

    ユーザー->>UI: 開始
    UI->>+Timer: タイマー開始
    Timer->>Timer: 設定時間を保持

    Timer->>+Storage: タイマー履歴を保存
    Storage-->>-Timer: 保存完了

    Timer-->>-UI: 開始受付完了

    loop カウントダウン中
        Timer->>Timer: 残時間を更新（終了予定時刻 - 現在時刻）
        Timer->>UI: 残時間を更新
        UI->>ユーザー: 残時間を表示
    end

    Timer->>Timer: タイマー終了状態へ遷移
    Timer->>Notify: タイマー終了通知を発生
    Notify->>UI: タイマー終了通知を表示

    alt 最初に発生した通知の場合
        Notify->>+Audio: 通知音の再生を依頼
        Audio-->>-Notify: 再生結果を通知
        Note over Audio: 通知音の再生は最大60秒
    else 先行する通知がある場合
        Note over Notify,Audio: 通知音は再生しない
    end

    Note over Notify,UI: 通知音終了後も終了操作まで通知状態と表示を維持

    ユーザー->>UI: 終了
    UI->>+Notify: タイマー終了通知を終了
    Notify->>+Audio: 対象通知の音声停止を依頼
    Audio-->>-Notify: 音声停止完了
    Notify->>UI: タイマー終了通知を非表示
    Notify-->>Timer: タイマー終了通知の終了

    Timer->>Timer: 設定時間・残時間・終了予定時刻・タイマー状態を初期化
    Timer->>UI: タイマー初期状態を通知
    UI->>ユーザー: 00:00:00を表示
    Notify-->>-UI: 通知終了処理完了
```

## 2. タイマー一時停止・再開
```mermaid
sequenceDiagram
    actor ユーザー
    participant UI as タイマー画面
    participant Timer as タイマー処理

    ユーザー->>UI: 時間を設定
    UI->>+Timer: タイマー設定時間を設定
    Timer-->>-UI: 設定完了

    ユーザー->>UI: 開始
    UI->>+Timer: タイマー開始
    Timer->>Timer: 設定時間を保持
    Timer-->>-UI: 開始受付完了

    loop カウントダウン中
        Timer->>Timer: 残時間を更新（終了予定時刻 - 現在時刻）
        Timer->>UI: 残時間を更新

        alt 一時停止
            ユーザー->>UI: 一時停止
            UI->>+Timer: 一時停止
            Timer->>Timer: 現在の残時間を秒単位で保持
            Timer->>Timer: カウントダウンを停止
            Timer-->>-UI: 一時停止状態を通知
            UI->>ユーザー: 一時停止状態と残時間を表示

            ユーザー->>UI: 再開
            UI->>+Timer: 再開
            Timer->>Timer: 保持した残時間から終了予定時刻を再設定
            Timer->>Timer: カウントダウンを再開
            Timer-->>-UI: 実行中状態を通知
        end
    end
```

## 3. タイマーカウントダウン中キャンセル
```mermaid
sequenceDiagram
    actor ユーザー
    participant UI as タイマー画面
    participant Timer as タイマー処理

    ユーザー->>UI: キャンセル
    UI->>+Timer: キャンセル確認開始
    Timer->>Timer: 現在の残時間を秒単位で保持
    Timer->>Timer: カウントダウンを停止
    Timer-->>-UI: 停止完了
    UI->>ユーザー: キャンセル確認画面を表示

    alt 「はい」
        ユーザー->>UI: はい
        UI->>+Timer: タイマーをキャンセル
        Timer->>Timer: 設定時間・残時間・終了予定時刻・タイマー状態を破棄
        Note over Timer: タイマー履歴は保持する
        Timer->>UI: タイマー初期状態を通知
        UI->>ユーザー: 00:00:00を表示
        Timer-->>-UI: キャンセル完了

    else 「いいえ」
        ユーザー->>UI: いいえ
        UI->>+Timer: キャンセル確認を取り消す
        Timer->>Timer: 保持している残時間からカウントダウンを再開
        Timer->>UI: 実行中状態を通知
        UI->>ユーザー: カウントダウンを再表示
        Timer-->>-UI: 再開完了
    end
```

## 5. アラーム通知中_タイマー終了
```mermaid
sequenceDiagram
    actor ユーザー
    participant Alarm as アラーム処理
    participant Timer as タイマー処理
    participant Notify as 通知管理処理
    participant UI as 画面
    participant Audio as 音声処理

    Alarm->>Notify: アラーム通知を発生
    Notify->>UI: アラーム通知を表示
    Notify->>+Audio: 通知音の再生を依頼
    Audio-->>-Notify: 再生開始

    loop タイマー終了まで
        Timer->>Timer: 残時間を更新（終了予定時刻 - 現在時刻）
    end

    Timer->>Notify: タイマー終了通知を発生
    Notify->>UI: タイマー終了通知を追加表示

    Note over Notify: アラーム通知とタイマー終了通知を独立管理
    Note over Notify,Audio: 最初のアラーム通知の音声を優先
    Note over Notify,UI: タイマー終了通知は終了操作まで表示を維持

    ユーザー->>UI: タイマー終了通知の「終了」
    UI->>+Notify: タイマー終了通知を終了
    Notify->>UI: タイマー終了通知を非表示
    Notify-->>-UI: 通知終了処理完了

    Note over Alarm,Notify: アラーム通知とその音声は継続
```

## 6. タイマー通知中_アラーム通知
```mermaid
sequenceDiagram
    actor ユーザー
    participant Timer as タイマー処理
    participant Alarm as アラーム処理
    participant Notify as 通知管理処理
    participant UI as 画面
    participant Audio as 音声処理

    Timer->>Notify: タイマー終了通知を発生
    Notify->>UI: タイマー終了通知を表示
    Notify->>+Audio: 通知音の再生を依頼
    Audio-->>-Notify: 再生開始

    Alarm->>Notify: アラーム通知を発生
    Notify->>UI: アラーム通知を追加表示

    Note over Notify: タイマー通知とアラーム通知を独立管理
    Note over Notify,Audio: 最初に発生したタイマー通知の音声を優先
    Note over Notify,UI: アラーム通知によってタイマー通知を中断しない

    ユーザー->>UI: タイマー通知の「終了」
    UI->>+Notify: タイマー通知を終了
    Notify->>+Audio: タイマー通知に対応する音声を停止
    Audio-->>-Notify: 音声停止完了
    Notify->>UI: タイマー通知を非表示
    Notify-->>-UI: 通知終了処理完了

    Note over Notify,UI: アラーム通知は継続表示
```
