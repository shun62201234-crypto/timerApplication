# タイマーシーケンス図
## 1. タイマー開始～終了（通常ケース）
```mermaid
sequenceDiagram
    autonumber
    actor User as ユーザー
    participant UI as タイマー画面
    participant Timer as タイマー管理
    participant Storage as 保存領域
    participant Clock as 時刻管理
    participant Notify as 通知管理

    User->>UI: 時間を設定
    UI->>Timer: タイマー設定時間を設定
    Timer-->>UI: 設定完了

    User->>UI: 開始
    UI->>Timer: タイマー開始

    alt 設定時間が00:00:00
        Timer-->>UI: 開始不可を通知
        UI->>User: 開始できないことを表示

    else 設定時間が00:00:00以外
        Timer->>Timer: 設定時間を保持
        Timer->>Storage: タイマー履歴を保存

        alt 保存成功
            Storage-->>Timer: 保存完了
            Timer->>Clock: 現在時刻を取得
            Clock-->>Timer: 開始時刻
            Timer->>Timer: 開始時刻・終了予定時刻を設定
            Timer->>Timer: カウントダウン開始
            Timer-->>UI: 開始受付完了

            loop カウントダウン中
                Timer->>Clock: 現在時刻を取得
                Clock-->>Timer: 現在時刻
                Timer->>Timer: 残時間を更新（終了予定時刻 - 現在時刻）
                Timer->>UI: 残時間を通知
                UI->>ユーザー: 残時間を表示
            end

            Timer->>Timer: カウントダウン停止
            Timer->>Timer: タイマー終了状態へ遷移
            Timer->>Notify: タイマー終了通知の登録を依頼
            Note over Timer,Notify: 通知登録・表示・音声再生は共通図1.1・2.1に従う
            Note over Notify,UI: 通知音は最大60秒で停止するが、通知表示と通知状態は終了操作まで維持する

            User->>UI: タイマー終了通知の終了操作
            UI->>Notify: タイマー終了通知の終了を依頼
            Note over Notify: 通知終了処理は共通図1.2に従う
            Notify-->>Timer: タイマー終了通知の終了

            Timer->>Timer: 設定時間・残時間・終了予定時刻・タイマー状態を初期化
            Timer->>UI: タイマー初期状態を通知
            UI->>ユーザー: 00:00:00を表示

        else 保存失敗
            Storage-->>Timer: 保存失敗
            Timer->>Timer: 開始前の状態を維持
            Timer-->>UI: 開始失敗を通知
            UI->>ユーザー: エラーを表示
            Note over Timer,UI: カウントダウン開始・通知登録は行わない
        end
    end

```

## 2. タイマー一時停止・再開
```mermaid
sequenceDiagram
    autonumber
    actor User as ユーザー
    participant UI as タイマー画面
    participant Timer as タイマー管理

    Note over UI,Timer: タイマー実行中の状態から開始

    loop タイマー終了まで
        Timer->>Timer: 残時間を更新（終了予定時刻 - 現在時刻）
        Timer->>UI: 残時間を通知
        UI->>User: 残時間を表示

        opt ユーザーが一時停止
            User->>UI: 一時停止
            UI->>+Timer: 一時停止
            Timer->>Timer: 現在の残時間を秒単位で保持
            Timer->>Timer: カウントダウンを停止
            Timer-->>-UI: 一時停止状態を通知
            UI->>User: 一時停止状態と残時間を表示

            User->>UI: 再開
            UI->>+Timer: 再開
            Timer->>Timer: 保持した残時間から終了予定時刻を再設定
            Timer->>Timer: カウントダウンを再開
            Timer-->>-UI: 実行中状態を通知
            UI->>User: カウントダウンを表示
        end
    end
```

## 3. タイマーカウントダウン中キャンセル
```mermaid
sequenceDiagram
    autonumber
    actor User as ユーザー
    participant UI as タイマー画面
    participant Timer as タイマー管理

    Note over UI,Timer: タイマー実行中の状態から開始

    User->>UI: キャンセル
    UI->>+Timer: キャンセル確認開始
    Timer->>Timer: 現在の残時間を秒単位で保持
    Timer->>Timer: カウントダウンを停止
    Timer-->>-UI: キャンセル確認開始を通知
    UI->>User: キャンセル確認画面を表示

    alt 「はい」
        User->>UI: はい
        UI->>+Timer: タイマーをキャンセル
        Timer->>Timer: 設定時間・残時間・終了予定時刻・タイマー状態を破棄
        Note over Timer: タイマー履歴は保持する
        Timer->>UI: タイマー初期状態を通知
        UI->>User: 00:00:00を表示
        Timer-->>-UI: キャンセル完了

    else 「いいえ」
        User->>UI: いいえ
        UI->>+Timer: キャンセル確認を取り消す
        Timer->>Timer: 保持した残時間から終了予定時刻を再設定
        Timer->>Timer: カウントダウンを再開
        Timer->>UI: 実行中状態を通知
        UI->>User: カウントダウンを再表示
    end
```

## 5. タイマー履歴の再利用
```mermaid
sequenceDiagram
    autonumber
    actor User as ユーザー
    participant UI as タイマー画面
    participant Timer as タイマー管理

    User->>UI: 履歴を選択
    UI->>Timer: 履歴選択要求（履歴ID）

    alt タイマーが開始待ち状態
        Timer->>Timer: 選択中の履歴を確認

        alt 別の履歴を選択
            Timer->>Timer: 以前の履歴選択を解除
            Timer->>Timer: 新しい履歴を選択
            Timer->>Timer: 履歴の設定時間を反映
            Timer-->>UI: 選択状態・設定時間
        else 選択中の履歴を解除
            Timer->>Timer: 履歴選択を解除
            Timer->>Timer: 設定時間を00:00:00に戻す
            Timer-->>UI: 未選択状態・初期設定時間
        end

    else タイマー実行中・一時停止中・終了通知中
        Timer-->>UI: 履歴選択不可
        UI-->>User: 設定時間を変更しない
    end

    Note over Timer: 履歴選択だけではタイマーを開始しない
    Note over Timer: 設定時間が00:00:00以外なら開始操作を受け付ける
```
