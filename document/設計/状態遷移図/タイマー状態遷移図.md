# タイマー状態遷移図

```mermaid
stateDiagram-v2

    [*] --> TIMER_INIT

    state "タイマー初期状態" as TIMER_INIT
    state "タイマー設定中" as TIMER_SETTING
    state "タイマー実行中" as TIMER_RUNNING
    state "タイマー一時停止中" as TIMER_PAUSED
    state "キャンセル確認中" as TIMER_CANCEL_CONFIRM
    state "タイマー終了通知中" as TIMER_NOTIFY

    TIMER_INIT --> TIMER_SETTING : 時間設定
    TIMER_INIT --> TIMER_SETTING : 履歴再利用

    TIMER_SETTING --> TIMER_SETTING : 時間変更
    TIMER_SETTING --> TIMER_SETTING : 別履歴選択
    TIMER_SETTING --> TIMER_INIT : 履歴選択解除
    TIMER_SETTING --> TIMER_RUNNING : 開始

    TIMER_RUNNING --> TIMER_PAUSED : 一時停止
    TIMER_PAUSED --> TIMER_RUNNING : 再開

    TIMER_RUNNING --> TIMER_CANCEL_CONFIRM : キャンセル
    TIMER_PAUSED --> TIMER_CANCEL_CONFIRM : キャンセル

    TIMER_CANCEL_CONFIRM --> TIMER_INIT : はい
    TIMER_CANCEL_CONFIRM --> TIMER_RUNNING : いいえ（実行中）
    TIMER_CANCEL_CONFIRM --> TIMER_PAUSED : いいえ（一時停止中）

    TIMER_RUNNING --> TIMER_NOTIFY : 残時間00:00:00
    TIMER_NOTIFY --> TIMER_INIT : 通知終了

    TIMER_RUNNING --> TIMER_INIT : アラーム通知中に終了

    TIMER_RUNNING --> [*] : ブラウザ終了
    TIMER_PAUSED --> [*] : ブラウザ終了
    TIMER_NOTIFY --> [*] : ブラウザ終了
