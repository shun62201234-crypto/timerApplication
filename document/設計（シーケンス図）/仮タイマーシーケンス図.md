<!-- シーケンス図① タイマー開始～終了 -->
sequenceDiagram
    actor ユーザー
    participant UI as タイマー画面
    participant Timer as タイマー処理
    participant Storage as LocalStorage
    participant Audio as 音声処理

    ユーザー->>UI: 時間を設定
    UI->>Timer: タイマー時間設定

    ユーザー->>UI: 開始
    UI->>Timer: タイマー開始
    Timer->>Timer: カウントダウン開始

    loop 残時間 > 0
        Timer->>UI: 残時間を更新
    end

    Timer->>UI: 残時間00:00:00
    Timer->>Audio: 通知音再生
    Audio-->>UI: 通知音再生開始

    Timer->>Storage: 開始時の設定時間を履歴保存

    Note over Audio: 最大60秒再生

    ユーザー->>UI: 終了
    UI->>Audio: 通知音停止
    UI->>UI: アラート終了

<!-- シーケンス図② タイマー一時停止・再開 -->
sequenceDiagram
    actor ユーザー
    participant UI as タイマー画面
    participant Timer as タイマー処理

    ユーザー->>UI: 開始
    UI->>Timer: カウントダウン開始

    loop カウントダウン
        Timer->>UI: 残時間更新
    end

    ユーザー->>UI: 一時停止
    UI->>Timer: 一時停止
    Timer->>Timer: 残時間を保持
    Timer-->>UI: 一時停止状態

    ユーザー->>UI: 再開
    UI->>Timer: 再開
    Timer->>Timer: 保持した残時間から再開

    loop カウントダウン
        Timer->>UI: 残時間更新
    end

    Timer->>UI: 残時間00:00:00

<!-- シーケンス図③ タイマーキャンセル -->
sequenceDiagram
    actor ユーザー
    participant UI as タイマー画面
    participant Timer as タイマー処理
    participant Storage as LocalStorage

    ユーザー->>UI: キャンセル
    UI->>Timer: カウントダウン一時停止
    UI->>UI: キャンセル確認画面表示

    alt 「はい」
        ユーザー->>UI: はい
        UI->>Timer: タイマー状態破棄
        Timer->>UI: 00:00:00へ戻す
        Note over Storage: 履歴には保存しない
    else 「いいえ」
        ユーザー->>UI: いいえ
        UI->>Timer: カウントダウン再開
    end
