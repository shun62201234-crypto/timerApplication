<!-- シーケンス図① モード切替中のタイマー -->
sequenceDiagram
    actor ユーザー
    participant Timer as タイマー処理
    participant UI as 画面
    participant Alarm as アラーム処理

    ユーザー->>UI: タイマー開始
    UI->>Timer: カウントダウン開始

    Timer->>UI: 残時間更新

    ユーザー->>UI: アラームへ切替
    UI->>Alarm: アラーム画面表示

    Note over Timer: タイマーは継続

    loop タイマー終了まで
        Timer->>Timer: カウントダウン
        Alarm->>Alarm: アラーム時刻監視
    end

    Timer->>Timer: タイマー終了

<!-- ブラウザ終了・再起動 -->
sequenceDiagram
    actor ユーザー
    participant Browser as ブラウザ
    participant Timer as タイマー処理
    participant Alarm as アラーム処理
    participant Storage as LocalStorage

    ユーザー->>Browser: ブラウザ終了

    Browser->>Timer: タイマー状態破棄
    Browser->>Alarm: 実行中状態破棄

    Note over Storage: 保存済みアラーム・履歴は保持

    ユーザー->>Browser: ブラウザ再起動

    Browser->>Alarm: アラーム処理開始
    Alarm->>Storage: 保存済みアラーム取得
    Storage-->>Alarm: アラーム設定

    Alarm->>Alarm: 現在時刻を取得

    alt 設定時刻が過去
        Alarm->>Alarm: 通知しない
    else 現在時刻以降
        Alarm->>Alarm: 通知対象として監視
    end

    Browser->>Timer: タイマー初期状態
    Timer-->>Browser: 00:00:00
