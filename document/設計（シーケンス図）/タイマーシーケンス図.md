# タイマーシーケンス図

## 1.タイマー開始～終了（通常ケース）
```mermaid
sequenceDiagram
    actor ユーザー
    participant UI as タイマー画面
    participant Timer as タイマー処理
    participant Storage as LocalStorage
    participant Audio as 音声処理

    ユーザー->>UI: 時間を設定
    UI->>Timer: タイマー設定時間を設定

    ユーザー->>UI: 開始
    UI->>Timer: タイマー開始
    Timer->>Timer: 開始時刻を記録
    Timer->>Timer: 終了予定時刻を算出
    Timer->>Timer: カウントダウン開始

    loop カウントダウン中
        Timer->>UI: 残時間を更新
    end

    Timer->>UI: 残時間00:00:00
    Timer->>UI: タイマー終了通知を表示
    Timer->>Audio: 通知音再生
    Audio-->>UI: 通知音再生開始

    Note over Audio: 通知音は最大60秒間再生
    Note over UI: 通知音終了後も通知終了操作まで通知状態を維持

    alt ユーザーが「終了」を押下
        ユーザー->>UI: 終了
        UI->>Audio: 通知音停止
        UI->>Timer: タイマー終了通知を終了
        Timer->>Storage: タイマー履歴を保存
        Timer->>UI: タイマー初期状態へ戻す
    else ブラウザ終了
        ユーザー->>UI: ブラウザ終了
        UI->>Timer: タイマー状態を破棄
        Note over Storage: タイマー履歴は保存しない
    end

## 2.タイマー一時停止・再開
```mermaid
sequenceDiagram
    actor ユーザー
    participant UI as タイマー画面
    participant Timer as タイマー処理

    ユーザー->>UI: 開始
    UI->>Timer: タイマー開始
    Timer->>Timer: 開始時刻を記録
    Timer->>Timer: 終了予定時刻を算出
    Timer->>Timer: カウントダウン開始

    loop カウントダウン中
        Timer->>UI: 残時間を更新
        alt タイマーを一時停止
            ユーザー->>UI: 一時停止
            UI->>Timer: 一時停止
            Timer->>Timer: 現在の残時間を秒単位で保持
            Timer-->>UI: 一時停止状態を通知

            ユーザー->>UI: 再開
            UI->>Timer: 再開
            Timer->>Timer: 保持した残時間から終了予定時刻を再設定
            Timer->>Timer: カウントダウン再開
        end
    end

    Timer->>UI: 残時間00:00:00

## 3.タイマーキャンセル
```mermaid
sequenceDiagram
    actor ユーザー
    participant UI as タイマー画面
    participant Timer as タイマー処理

    alt カウントダウン中からキャンセル
        ユーザー->>UI: キャンセル
        UI->>Timer: カウントダウン一時停止
        UI->>UI: キャンセル確認画面表示

        alt 「はい」
            ユーザー->>UI: はい
            UI->>Timer: タイマーをキャンセル
            Timer->>Timer: 設定時間と残時間を破棄
            Timer->>UI: タイマー初期状態へ戻す
            Note over Timer: 履歴には保存しない
        else 「いいえ」
            ユーザー->>UI: いいえ
            UI->>Timer: キャンセル確認前の状態へ復帰
            Timer->>Timer: カウントダウン再開
        end

    else 一時停止中からキャンセル
        ユーザー->>UI: キャンセル
        UI->>UI: キャンセル確認画面表示

        alt 「はい」
            ユーザー->>UI: はい
            UI->>Timer: タイマーをキャンセル
            Timer->>Timer: 設定時間と残時間を破棄
            Timer->>UI: タイマー初期状態へ戻す
            Note over Timer: 履歴には保存しない
        else 「いいえ」
            ユーザー->>UI: いいえ
            UI->>Timer: キャンセル確認前の状態へ復帰
            Timer->>Timer: 一時停止状態を維持
        end
    end

## 4.追加：アラーム通知中にタイマーが終了するケース
```mermaid
sequenceDiagram
    actor ユーザー
    participant Alarm as アラーム処理
    participant Timer as タイマー処理
    participant UI as アラーム通知画面
    participant Storage as LocalStorage

    Alarm->>UI: アラーム通知画面を表示
    Alarm->>Alarm: アラーム通知状態を維持

    Timer->>Timer: カウントダウン継続
    loop タイマー終了まで
        Timer->>Timer: 残時間を更新
    end

    Timer->>Timer: 残時間00:00:00
    Timer->>Timer: タイマーを終了
    Timer->>Storage: タイマー履歴を保存
    Storage-->>Timer: 保存完了

    Timer->>UI: タイマー終了テロップ表示

    Note over UI: テロップを5秒間表示
    Note over UI: アラーム通知画面は継続表示

    UI->>UI: 5秒経過
    UI->>UI: テロップを非表示

    Note over Alarm: アラーム通知は継続

## 5.タイマー終了通知中にアラーム時刻へ到達した場合
```mermaid
sequenceDiagram
    actor ユーザー
    participant Timer as タイマー処理
    participant Alarm as アラーム処理
    participant UI as 画面
    participant Audio as 音声処理
    participant Storage as LocalStorage

    Timer->>UI: タイマー終了通知を表示
    Timer->>Audio: タイマー通知音再生

    Alarm->>Alarm: 現在時刻を判定
    Alarm->>UI: アラーム通知へ切り替え
    Alarm->>Audio: アラーム音再生

    Note over UI: アラーム通知を優先

    UI->>Timer: タイマー終了通知を終了
    UI->>Audio: タイマー通知音停止

    Note over Timer,Storage: タイマー履歴の保存タイミングは別途仕様定義
