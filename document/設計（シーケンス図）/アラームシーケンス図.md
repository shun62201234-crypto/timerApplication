<!-- シーケンス図① アラーム登録 -->
sequenceDiagram
    actor ユーザー
    participant UI as アラーム画面
    participant Alarm as アラーム処理
    participant Storage as LocalStorage

    ユーザー->>UI: 追加
    UI->>Alarm: 新規アラーム設定開始

    ユーザー->>UI: 時刻をスクロール設定
    UI->>Alarm: 時刻設定

    ユーザー->>UI: 保存
    UI->>Alarm: アラーム登録
    Alarm->>Alarm: ON状態で登録
    Alarm->>Storage: アラーム設定保存
    Storage-->>Alarm: 保存完了
    Alarm-->>UI: アラーム一覧更新

    UI->>UI: 設定状態終了

<!-- シーケンス図② アラーム通知 -->
sequenceDiagram
    participant Browser as ブラウザ
    participant Alarm as アラーム処理
    participant Clock as JST時刻
    participant Storage as LocalStorage
    participant UI as アラーム画面
    participant Audio as 音声処理

    Browser->>Alarm: 起動
    Alarm->>Storage: アラーム設定取得
    Storage-->>Alarm: 保存済みアラーム

    loop ブラウザ起動中
        Alarm->>Clock: 現在時刻取得
        Clock-->>Alarm: JST現在時刻

        alt ON状態かつ設定時刻到達
            Alarm->>UI: アラート表示
            Alarm->>Audio: アラーム音再生
            Audio-->>UI: アラーム音再生開始

            Note over Audio: 最大60秒再生

            alt ユーザーが終了
                ユーザー->>UI: 終了
                UI->>Audio: 音声停止
                UI->>UI: アラート終了
            else ユーザーがスヌーズ
                ユーザー->>UI: スヌーズ
                UI->>Alarm: スヌーズ開始
            end
        else OFF状態
            Alarm->>Alarm: 通知しない
        end
    end

<!-- 
なお、「ブラウザ起動時にすでに設定時刻を過ぎている場合」は、
ブラウザ起動
    ↓
現在時刻取得
    ↓
設定時刻 < 現在時刻
    ↓
過去の時刻なので通知しない
となります。 
-->

<!-- シーケンス図③ アラーム通知～スヌーズ -->
sequenceDiagram
    actor ユーザー
    participant UI as アラート画面
    participant Alarm as アラーム処理
    participant Timer as スヌーズタイマー
    participant Audio as 音声処理

    Alarm->>UI: アラーム通知
    Alarm->>Audio: アラーム音再生

    alt 終了
        ユーザー->>UI: 終了
        UI->>Audio: 音声停止
        UI->>Alarm: 通知終了
        Alarm->>UI: 通常アラーム画面
    else スヌーズ
        ユーザー->>UI: スヌーズ
        UI->>Audio: 音声停止
        UI->>Timer: 5分タイマー開始

        Timer->>UI: スヌーズ残時間表示

        Note over Timer: 5分経過

        Timer->>Alarm: スヌーズ終了
        Alarm->>UI: 再度アラート表示
        Alarm->>Audio: アラーム音再生

        alt 再度スヌーズ
            ユーザー->>UI: スヌーズ
            UI->>Timer: 5分タイマー再開
        else 終了
            ユーザー->>UI: 終了
            UI->>Audio: 音声停止
            UI->>Alarm: 通知終了
        end
    end

<!-- 
この図では、スヌーズ回数に上限がないため、
通知
 ↓
スヌーズ
 ↓
5分
 ↓
通知
 ↓
スヌーズ
 ↓
5分
 ↓
通知
 ↓
...
というループになります。 
-->

<!-- シーケンス図④ アラーム通知中にタイマーが終了した場合 -->
sequenceDiagram
    actor ユーザー
    participant Timer as タイマー処理
    participant Alarm as アラーム処理
    participant UI as アラート画面
    participant Audio as 音声処理

    Note over Timer: タイマー実行中
    Note over Alarm: アラーム通知中

    Timer->>Timer: カウントダウン継続
    Alarm->>UI: アラームアラート表示
    Alarm->>Audio: アラーム音再生

    Timer->>Timer: 残時間00:00:00
    Timer->>Timer: タイマー終了

    Note over Timer,UI: アラーム通知中のため<br/>タイマー終了通知は行わない

    Timer-->>Timer: タイマー終了通知を抑制

    Note over Alarm: アラーム通知は継続

    alt ユーザーが終了
        ユーザー->>UI: 終了
        UI->>Audio: アラーム音停止
        UI->>Alarm: アラーム通知終了
    else ユーザーがスヌーズ
        ユーザー->>UI: スヌーズ
        UI->>Audio: アラーム音停止
        UI->>Alarm: スヌーズ開始
    end

<!-- 
これによって、「タイマーが終了した＝必ずタイマー終了アラートを出す」ではないことを明確にできます。
つまり、今回の仕様では、
タイマー終了
    │
    ├─ 通常状態
    │    └─ タイマー終了通知する
    │
    └─ アラーム通知中／スヌーズ中
         └─ タイマー終了通知しない
という分岐になります。 
-->
