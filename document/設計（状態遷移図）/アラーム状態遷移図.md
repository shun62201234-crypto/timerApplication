```mermaid
stateDiagram-v2

    [*] --> ALARM_NORMAL

    state "アラーム通常状態" as ALARM_NORMAL
    state "アラーム設定中" as ALARM_SETTING
    state "アラーム削除選択中" as ALARM_DELETE_SELECT
    state "アラーム通知中" as ALARM_NOTIFY

    ALARM_NORMAL --> ALARM_SETTING : 追加

    ALARM_NORMAL --> ALARM_DELETE_SELECT : アラーム選択
    ALARM_DELETE_SELECT --> ALARM_DELETE_SELECT : アラーム選択

    ALARM_DELETE_SELECT --> ALARM_NORMAL : 削除
    ALARM_DELETE_SELECT --> ALARM_NORMAL : 全選択解除

    ALARM_NORMAL --> ALARM_NOTIFY : ON状態・設定時刻到達

    ALARM_NOTIFY --> ALARM_NORMAL : 終了
    ALARM_NOTIFY --> ALARM_SNOOZE : スヌーズ

    ALARM_SNOOZE --> ALARM_NOTIFY : 5分経過
    ALARM_SNOOZE --> ALARM_NORMAL : 終了
